# Rival Architecture v0.1

- 상태: `HIGH_LEVEL_LOCKED / DETAILS_UNDER_REVIEW`
- 기능: 강백호-서태웅식 국내 대비를 복제하지 않고, 두 선수가 서로 다른 경로와 농구 가치로 NBA에서 다시 만나는 장기 라이벌

## 고정 경로

한국 엘리트 선수 → 미국 명문 프렙 → Duke급 블루블러드 → 2019-20 NCAA → 2020 합의·실제 드래프트 1순위 → NBA 프랜차이즈 에이스

정확한 프렙 학교, 대학명, 2020년 1순위 보유 팀은 아직 HOLD다. 주인공이 2018-20 순위와 픽을 바꾸므로 실제 Minnesota를 자동 유지하지 않는다.

## 기능 대비

| 항목 | 주인공 | 라이벌 |
|---|---|---|
| 국내 출발 | 늦게 배운 신체 원석 | 이미 완성도 높은 엘리트 |
| 포지션 | 203cm SF/PF, 상황에 따라 소형 5번 | 약 198cm SG/SF |
| 1차 무기 | 리바운드·수비·전환·연결 패스 | 풋워크·풀업·림 압박·POA 수비 |
| 성공 시점 | 2018 NBA 선진입 | 프렙·대학을 거쳐 2020 1순위 |
| NBA 문제 | 슈팅 중력 없는 연결자의 한계 | 온볼 점유가 팀 천장을 막는 한계 |
| 최종 성장 | 라인업을 살리는 플레이오프 지휘자 | 더블팀을 읽고 오프볼도 지배하는 에이스 |

## 관계 단계

1. 국내: 라이벌은 농구 언어를 이미 알고, 주인공은 몸만 안다.
2. 미국: 서로 다른 학교와 평가 체계에서 비교가 끊긴다.
3. 2018-20: 주인공은 먼저 NBA에 들어가지만 라이벌은 더 높은 기대치로 뒤쫓는다.
4. 2020 드래프트: 1순위라는 외부 평가가 둘의 성공을 단순 서열로 보이게 한다.
5. NBA: 직접 맞대결보다 역할·계약·플레이오프 성취가 경쟁 축이 된다.
6. 결말권: 서로의 장점을 흉내 내지 않고 상대의 가치가 필요한 순간을 인정한다.

## 금지

- 라이벌을 주인공의 성장 측정기나 질투 악역으로 축소
- 둘 다 레너드형 무표정 투웨이 윙으로 수렴
- Duke·2020 1순위를 유명세 장식으로만 사용
- 실제 2020 대학 포스트시즌 취소를 무시
- 주인공 때문에 모든 실존 유망주가 비합리적으로 밀리는 전개
