# Rival Architecture v0.3

- 상태: `HIGH_LEVEL_LOCKED / DETAILS_UNDER_REVIEW`
- 기능: 강백호-서태웅식 국내 대비를 복제하지 않고, 두 선수가 서로 다른 경로와 농구 가치로 NBA에서 다시 만나는 장기 라이벌

## 고정 경로

한국 엘리트 선수 → 2017년 오른쪽 ACL 완전파열·재건술 → 2018년 Gonzaga 입학·공식전 0경기 레드셔츠 → 2019-20 WCC 우승·복귀 시즌 → 2020 합의·실제 드래프트 1순위 수준 → NBA 프랜차이즈 에이스

라이벌은 별도의 미국 프렙을 거치지 않고 Gonzaga로 간다. 부상 경기·수술 세부, 장학금 counter, 2019-20 기록, 2020년 실제 지명 팀·순번은 아직 HOLD다. 주인공이 2018-20 순위와 픽을 바꾸므로 실제 Minnesota나 실제 1순위를 자동 유지하지 않는다.

## 기능 대비

| 항목 | 주인공 | 라이벌 |
|---|---|---|
| 국내 출발 | 늦게 배운 신체 원석 | 이미 완성도 높은 엘리트 |
| 포지션 | 203cm SF/PF, 상황에 따라 소형 5번 | 약 198cm SG/SF |
| 1차 무기 | 리바운드·수비·전환·연결 패스 | 풋워크·풀업·림 압박·POA 수비 |
| 성공 시점 | 2018 NBA 선진입 | ACL 재활·NCAA 복귀를 거쳐 2020 1순위 수준 |
| NBA 문제 | 슈팅 중력 없는 연결자의 한계 | 온볼 점유가 팀 천장을 막는 한계 |
| 최종 성장 | 라인업을 살리는 플레이오프 지휘자 | 더블팀을 읽고 오프볼도 지배하는 에이스 |

## 관계 단계

1. 국내: 라이벌은 농구 언어를 이미 알고, 주인공은 몸만 안다.
2. 분리: 주인공은 미국 프렙·Villanova로 이동하고, 라이벌은 한국 고교 마지막 시즌의 ACL 부상으로 경쟁 시간을 잃는다.
3. 2018-20: 주인공은 먼저 NBA에 들어가지만 라이벌은 더 높은 기대치로 뒤쫓는다.
4. 2020 드래프트: 1순위라는 외부 평가가 둘의 성공을 단순 서열로 보이게 한다.
5. NBA: 직접 맞대결보다 역할·계약·플레이오프 성취가 경쟁 축이 된다.
6. 결말권: 서로의 장점을 흉내 내지 않고 상대의 가치가 필요한 순간을 인정한다.

## 부상·복귀 기능

- 2017년 9월 후보창의 한국 고교 공식 경기에서 비접촉 방향전환 중 오른쪽 ACL이 완전파열된다.
- 2017년 10월 재건술 뒤 단계별 재활을 시작하고, 2018년 가을 부상 전부터 영입하던 Gonzaga에 입학한다.
- 2018-19 공식 경기에는 출전하지 않는다. 이는 hardship waiver가 아니라 0경기 전통 레드셔츠다.
- 2019-20 복귀 첫해에는 폭발력·효율·부하 관리의 편차를 남긴다.
- 급격한 방향전환 일변도에서 감속·두 발 정지·템포·풀업·선제 패스를 함께 쓰는 1차 창조자로 확장한다.
- 부상은 인성 교정·신체 강화·주인공 추월 보너스가 아니다.

## Gonzaga 기능

- 2018-19은 공식 경기 0회로 기다림과 팀 적응을 치른다.
- 2019-20에는 선발 SG/SF·외곽 1차 창조자로 복귀하고 WCC 정규시즌·토너먼트 우승 기능을 얻는다.
- 깊은 관계는 Joel Ayayi·Corey Kispert·Filip Petrusev 세 명, 대표 경기는 Oregon전·Saint Mary's WCC 결승 두 개가 상한이다.
- 전국우승은 없다. 2020 NCAA 포스트시즌 취소가 마지막 검증 기회를 끊는다.

## 금지

- 라이벌을 주인공의 성장 측정기나 질투 악역으로 축소
- 둘 다 레너드형 무표정 투웨이 윙으로 수렴
- 대학명·2020 1순위를 유명세 장식으로만 사용
- 《슬램덩크》식 충돌 부상·통증 은폐·영웅적 강행 복귀를 복제
- 2018-19 일부 출전과 hardship waiver를 0경기 레드셔츠와 혼용
- 실제 2020 대학 포스트시즌 취소를 무시
- 주인공 때문에 모든 실존 유망주가 비합리적으로 밀리는 전개
