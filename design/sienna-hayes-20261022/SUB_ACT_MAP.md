# 시에나 서브액트맵

12개 관계 기능, 본문 작성/반영0, 새 회차0. 장면 분량은 공백 포함 글자 수의 편집 제안이며 기존 화 분량을 실측해 배정한 값이 아니다. 기능을 합칠 수 있고 전부 새 독립 화로 늘리지 않는다.

## SH01 — 촬영할 때와 다른 얼굴

- 시기/연결: 2018-08 / SH-R1
- 삽입: 현행 EP42 말미 이후~EP43 첫 문단 이전의 8월 시간 경계
- 목적: 정해진 시간 안에 자기 촬영을 마치기
- 방해: 태오는 정적인 포즈에 굳고 시에나도 자기 결과가 마음에 들지 않음
- 선택과 행동: 시에나가 대기 중 말을 걸고 태오도 짧은 농담으로 응답 / 각자 촬영/결과 확인/대기 대화
- 결과 → 다음: 태오는 이름과 직업, 겉으로 드러난 긴장만 알게 됨 → 연락처를 직접 묻는 다음 행동
- 제안 분량: 900~1300자. 줄일 대목: 서머리그 결말과 캠프 경기 삭제 없음. 훗날 전환 설명의 중복분과 분량을 교환
- 중단/전환: 훈련·의무 일정과 겹치면 촬영을 옮김. 불가능하면 9월캠프 전 다른 조율창으로 재배치
- 복선/회수: 작업용 미소와 결과를 다시 보는 표정의 차이 → SH02의 자발적 연락
- POV: 태오가 듣고 보는 말·표정만. 시에나의 확정 속마음 없음
- Pack: [설계용 SH01](../../context-packs/sienna-hayes-design/SH01.json)

## SH02 — 일이 끝난 뒤의 연락

- 시기/연결: 2018-08 / SH-R1
- 삽입: SH01과 같은 촬영 종료 경계. 새 회차 번호 부여 없음
- 목적: 업무 밖에서도 이야기하고 싶은지 알아보기
- 방해: 촬영 종료 뒤에는 더 만날 이유가 없음
- 선택과 행동: 시에나가 직접 연락처 교환을 제안하고 태오가 응함 / 본인 휴대폰으로 서로 입력·귀가 뒤 짧은 메시지
- 결과 → 다음: 상호 동의한 사적 연락 경로 → SH03에서 태오도 먼저 연락
- 제안 분량: 250~450자. 줄일 대목: SH01과 합칠 수 있음; 별도 화를 만들지 않음
- 중단/전환: 상대가 망설이면 재촉/직원 통한 입수 없음
- 복선/회수: 태오가 들은 다음 오디션 일정(날짜는 생략) → SH03에서 결과를 먼저 물음
- POV: 그녀가 직접 말한 범위만; 연락처 전달을 담당자에게 부탁하지 않음
- Pack: [설계용 SH02](../../context-packs/sienna-hayes-design/SH02.json)

## SH03 — 내 쪽에서 먼저 묻는 안부

- 목적: 다음 대화를 업무 핑계 없이 이어 가기
- 방해: 태오는 받는 질문에만 답하기 쉬움
- 선택과 행동: 태오가 그녀가 말했던 오디션 결과를 먼저 물음 / 경기/이동 중 아닌 개인 시간에 짧은 연락
- 결과 → 다음: 둘 다 대화를 시작하는 사이 → SH04에서 따로 만나자는 제안
- 제안 분량: 150~300자. 줄일 대목: 비슷한 자기 평가/다음 경기 예고 한 단락과 교환 후보
- 중단/전환: 경기 중 휴대폰 사용·훈련 이탈이면 배치 중단
- 복선/회수: SH02의 작고 구체적인 말 → 상대 말을 기억하는 행동
- POV: 시에나의 답을 통해서만 그녀의 생활을 앎

## SH04 — 촬영 말고 만나는 날

- 시기/연결: 2018가을~2019초 / SH-R2
- 삽입: 정확 휴식일·이동이 확보될 때만; 12월7일 지각 밤과 겹치지 않음
- 목적: 사적으로 보고 싶은 마음을 분명히 하기
- 방해: Chicago와New York의 실제 여유시간이 다름
- 선택과 행동: 태오가 만남을 제안하고 서로 가능한 시간에 식사; 이후 두 사람이 연인 관계를 말로 확인 / 이동·업무가 없는 조율창의 식사와 대화
- 결과 → 다음: 겨울~2019초에 상호 확인한 연인 → SH05의 약속을 존중할 책임
- 제안 분량: 700~1100자. 줄일 대목: 데이트와 관계 확인은 시간 경과로 분리 가능; 매경기 후 식사 반복 금지
- 중단/전환: 일정 불일치면 실제 만남을 연기하고 연락 유지. 훈련취소/가짜출장 없음
- 복선/회수: 서로 농구/모델 일이 없던 시절의 작은 취향 → 이후 일상 연락의 내용
- POV: 과거 삶은 본인이 말한 내용만. 시에나 시점의 독백 없음
