# Master Architecture

- 상태: `DRAFT`
- 구조 원칙: 결말에서 역산하고, 각 구간은 주인공의 능력보다 **맡길 수 있는 책임의 크기**를 키운다.

## 전 작품 변화축

`발견 → 규율 → 이동 → 생존 → 역할 → 신뢰 → 시장 평가 → 팀 선택 → 우승 선택`

## 세 축

1. **기술축**: 운동능력 의존 → 리바운드 기술 → 수비 판단 → 전환과 패스 → 투웨이 창조
2. **관계축**: 인정 투쟁 → 역할 충돌 → 상호 의존 → 동료의 선택을 살리는 리더십
3. **제도축**: 한국 고교 등록 → 프렙 학사/노출 → NCAA 자격/역할 → 드래프트 평가 → NBA 계약/로스터/우승창

어느 Act도 기술축만으로 끝내지 않는다. 관계와 제도 중 최소 하나의 상태가 함께 바뀌어야 한다.

## 경기 설계 단위

경기 전체를 반복 서술하지 않는다. 각 대표 경기는 서로 다른 질문을 갖는다.

- 출전할 자격이 있는가?
- 맡은 역할을 지킬 수 있는가?
- 더 큰 역할을 요구할 근거가 있는가?
- 팀 동료가 그의 판단을 믿는가?
- 시장 평가와 실제 가치가 왜 어긋나는가?
- 승리를 위해 자신의 하이라이트를 포기할 수 있는가?

## 연재 엔진

회차 보상은 능력치 숫자가 아니라 다음으로 만든다.

- 새 기술의 실전 증명
- 역할/출전시간/매치업의 변화
- 관계의 신뢰 또는 비용
- 제도적 문턱 통과
- 스카우팅 리포트의 평가 변화
- 실제 역사와 갈라지는 선택
- 다음 경기보다 다음 **결정**을 궁금하게 하는 후크

## 설계 방법 제한

Act별 주 방법은 1~2개, Sub-Act별 주 장치는 1개만 둔다. 모든 방법론을 한 구간에 겹치지 않는다. 기법 이름보다 목표·압력·선택·비용·상태 변화가 먼저다.
