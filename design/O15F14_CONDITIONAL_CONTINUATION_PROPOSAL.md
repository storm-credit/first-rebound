# O-15F14 — 자동 후속 작업의 조건부 결산 제안

- 상태: `CP2_WORKFLOW_APPROVED / FINAL_CANON_NOT_ADOPTED`.
- 작성 목적: 사용자의 ‘자동으로 끝까지 계속’을 실행하면서, 미확인 사실 때문에 같은 조사만 되풀이하지 않도록 다음 선택을 구체화한다.
- 직전 CP2 전환 질문에 대한 사용자의 ‘이어서’를 절차 승인으로 기록했다. [승인 원장](../canon/CHICAGO_2020_21_CP2_APPROVAL.json)에 따라 사실 해소 전 추첨 금지의 조건부 작업 예외를 적용한다.

## 1. 현재 자동 처리로 완료한 범위

PR #161~165와 이번 실행 조항 후속은 기존 추천을 바꾸지 않고 사건 선택·비용·등록·거래 근거를 연결했다. K1/BPM·L2의 전체 시즌과 플레이인 추천, 조건부 달력, Hall 신청 근거와 등록 1자리, 네 팀 급여 여유, 공개 픽 보호·종료가 한 패킷에 있다. 사전 승인된 Chicago·Minnesota·드래프트·Theis/Green·R1/T1~T4를 다시 선택할 필요는 없다.

남은 사실은 팀별 미포함 부담과 거래일 예외/charge의 정확 장부, 일부 미래 보호픽 연결/우선권이다. 공개 자료 조회로 회수하지 못한 값이 있으며 그 값을 0 또는 ‘의무 없음’으로 채택할 수 없다. 반면 이 미확보 항목들이 K1의 정규시즌 산술 자체를 새로 계산하게 만드는 것은 아니다. 현실 거래의 정확성 인증과 조건부 설계의 활용 범위를 구분할 필요가 있다.

## 2. 상호 배타적인 네 진행 방식

| ID | 진행 방식 | 얻는 결과와 비용 |
|---|---|---|
| CP1 | 현재 사실 게이트 유지 | 정확 원장·잔여 조항이 확보될 때까지 시즌/추첨 보류. 종전 방식이며 CP2 채택 후 조건부 작업에는 적용하지 않는다. |
| **CP2 채택** | **K1·L2를 조건부 작업 기준으로 채택하고 잠정 결산 허용** | 미확인 사실은 HOLD로 보존한 채 고정 seed의 추첨·보호픽 잠정 결산과 2021–23 이후 설계안을 계속 작성. 최종 정본 승격은 보류한다. |
| CP3 | 미확인 계약·행정 조항을 작품의 새 설정으로 하나씩 결정 | 별도의 계약 설정 선택이 필요하다. 공개 역사 검증 완료로 표현할 수 없으며 기존 승인 외 의무를 새로 만들 수 있어 추천하지 않는다. |
| CP4 | 거래·등록 경로를 다시 설계 | 기존 추천의 가용성·분·승패를 다시 연결해야 한다. 승인 방향을 불필요하게 재개방하므로 추천하지 않는다. |

CP2는 비용이나 미확인 조항의 값을 확정하는 안이 아니다. CP1의 ‘사실 해소 전 추첨 금지’를 **조건부 시뮬레이션에 한해** 바꾸는 작업 순서 제안이다. 직전 전환 질문에 대한 사용자의 진행 지시로 작업 절차를 채택했다. CP2를 채택해도 최종 정본·완성 게이트의 기준을 충족했다고 보고할 수 없다.

## 3. CP2를 선택할 경우 적용할 정확한 작업 기준

| 구분 | 조건부 작업 입력 | 유지할 미확정 |
|---|---|---|
| 가용성 | A1: K의 1,079행 달력·J1 Terry 27경기 공백 | 실제 의학적 확정 아님 |
| Hall 행정 | A2: 기존 4명 결장에 근거한 hardship 신청·승인을 작품의 조건부 사건으로 사용 | 실제 대체세계 승인 사실로 주장하지 않음. 양수 분 5경기에는 추가 자리 필요 |
| 정규시즌 | A3: K1/BPM 전체 경로, CHI 31–41·동부 10위, MIN 24–48·서부 13위 | RAPTOR 전체 경로는 교차검산으로 보존 |
| 플레이인 | L2: BOS>IND, CHI>WAS 후 IND>CHI; POR>GSW, MEM>SAS, MEM>GSW | 점수·개인 박스 미선택 |
| 추첨 | 기존 DRAFT_CAUSALITY_PROTOCOL의 고정 seed, CHI/NOP 동률부터 상위 4픽까지 한 번 실행 | 결과를 보고 seed·시즌안을 바꾸지 않음. 실제 역사 순번을 복사하지 않음 |
| 거래·급여 | 원권위의 공개 조건과 잔여 부담 허용 범위를 전제 조건으로 연결 | 실제 R·정확 charge·예외 잔액·미확인 픽 조항은 null/HOLD 유지 |
| 후속 설계 | 잠정 2021 픽 소유권을 조건으로 2021–23 거래·계약, 장기 커리어, 결말/Act, 문체 기준·Context Pack 초안까지 진행 | 새 중요 창작 결정은 4안 비교 후 추천안으로 기록. 작가 최종 확정과 혼동하지 않음 |

추첨 출력은 `PROVISIONAL_CONDITIONAL_RESULT`로 명명하고 `author_locked=false`, `season_selected=false`를 유지한다. CP2의 승인 기록은 작업 절차 선택이며 최종 시즌 정본 승인과 구분한다. 조건 변경이 필요한 실제 반례가 생기면 영향받는 결과만 재개방하고, 비교적 좋은 결과를 얻기 위한 재추첨을 하지 않는다.

F의 비상 역할 비용 반례, I의 Washington HIGH/RAPTOR 반례, K의 4경기 잔여 빅맨 중복은 보존한다. 최종 전체 독립 검수와 작가 승인은 별도이며, 이 제안에 포함되지 않는다. `PROJECT_FREEZE v0.30 PARTIAL`, 설계·원고 게이트 CLOSED를 유지한다. 원고를 작성하지 않는다.

## 4. 현재 적용 상태

CP2를 조건부 작업 절차로 채택했다. 원자료와 최종 author/season 플래그는 false를 유지한다. 결과를 보기 전에 입력·알고리즘을 먼저 게시하고 그 뒤 한 번 실행한다. 정확 미확인 사실과 최종 정본 승격은 계속 별도다. 같은 CP2 진행 승인을 다시 묻지 않는다.
