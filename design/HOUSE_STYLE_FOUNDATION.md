# 하우스 스타일 기초 — 설계 검토용

- 상태: `FOUNDATION_PARTIAL / REFERENCE_DEEP_READ_INCOMPLETE`.
- 적용 권위: `canon/STORY_BIBLE.md`, `canon/CAREER_TIMELINE.md`, `design/PLAYER_RELATIONSHIP_VOICE_MODEL.md`.
- 참고작 실제 열람 범위는 [접근·독서 원장](../research/STYLE_REFERENCE_ACCESS.md)에 별도 기록한다. 아래 규칙 대부분은 프로젝트의 성격·농구·권한 요구에서 만든 기초안이며 참고작 전체 딥리드의 결론이 아니다.
- 원고·대사 샘플0개. `manuscript_allowed=false`, G11 최종 PASS 아님.

## 서술 방식 네 안

| 안 | 초점과 정보 범위 | 비용 |
|---|---|---|
| **S1 추천** | 주인공 밀착 3인칭, 구간 경계에서만 표시된 제한 시점 전환 | 주인공이 모르는 계약·타팀 판단은 접근 경로를 따로 만들어야 함 |
| S2 | 주인공 1인칭 고정 | 상대·단장·의료 정보 접근 폭이 가장 좁음 |
| S3 | 매 회차 교차 제한 3인칭 | 라이벌의 독립성은 강해지나 회차 재진입 부담 증가 |
| S4 | 전지적 스포츠 연대기 | 리그 전체 설명은 편하나 주인공의 오판·발견이 약해짐 |

S1은 문체 추천이며 기존 정본의 시점 잠금을 덮어쓰지 않는다. 실시간 경기 중 멀리 있는 방송 해설·타팀 회의·타인의 속마음을 같은 문단에서 듣지 않는다. 공개 인터뷰·영상·당사자의 전달 등 정보 출처가 필요하다.

## KEEP — 보존할 기준

- 주인공은 평소 반응과 말수가 적다. 침착한 현인이나 냉소적인 말재주꾼으로 바꾸지 않는다. 자존심이 긁힌 때의 짧은 과장과 행동이 성격의 예외를 드러낸다.
- 경기의 핵심은 누가 어디에서 무엇을 했고, 상대가 어떻게 반응했으며, 그 결과 어느 공간과 선택이 열렸는지다.
- 리바운드는 숫자만이 아니라 박스아웃·궤도 판단·착지·첫 선택의 기능이다. 초반의 재능과 후반의 책임이 같은 행동에 다른 비용을 갖는다.
- 선수·코치·의료진·프런트·에이전트의 결정 권한을 구분한다. 인물의 정보와 전문성이 직함·경력·현재 상황을 넘지 않는다.
- 한국어로 한 번 들어도 행동과 논리를 복원할 수 있어야 한다. 고유명사·숫자·전술 용어가 연달아 나오면 독자가 지금 알아야 하는 것부터 남긴다.

## ADOPT — 적용할 기초 규칙

| 영역 | 작업 규칙 | 검사 질문 |
|---|---|---|
| 문단 | 기본 2~4문장에 한 행동·판단 흐름. 문장 수를 강제하지 않음 | 문장 사이 원인·결과가 이어지는가 |
| 단문 | 충격·선택·실패 순간의 강조에 제한 | 모든 문장이 단문이 되어 강약이 사라지지 않는가 |
| 긴 문단 | 공백 포함 200자 초과는 점검 대상 | 행위자·시간·목표가 바뀌는 지점만 나눴는가 |
| 대화 | 목적·관계·권한이 먼저, 정보 설명은 필요한 만큼 | 같은 말을 설명문이 바로 다시 해설하는가 |
| 농구 용어 | 처음 필요한 순간 행동/결과와 연결, 이후 반복 정의 생략 | 용어를 몰라도 열린 공간과 선택을 이해하는가 |
| 수치 | 점수·남은 시간·분·계약 중 해당 선택을 바꾸는 값만 전면 | 원장 숫자를 그대로 본문에 쏟지 않는가 |
| 회차 끝 | 다음 경기 예고보다 다음 결정의 비용을 남김 | 이미 끝난 설명을 질문형으로 반복하지 않는가 |
| 실제 인물 | 공개 농구 역할 범위와 허구 사건 기능을 구분 | 비공개 감정·할인 의사·의료 판단을 사실처럼 만들지 않는가 |

## AVOID — 피할 습관

- 체육관 행동을 전쟁·처형·지배 같은 추상 비유로 덮고 실제 공·발·수비 위치를 생략하기.
- 같은 승부에 행동→관중 반응→방송→내면 해설로 같은 의미를 네 번 설명하기.
- 라이벌을 실존 선수의 미래 통계·부상·수상 복제본으로 만들거나, 대립을 끝없이 트래시 토크로만 표시하기.
- 감독의 의도를 주인공이 즉시 모두 이해하거나, 에이전트가 출전·진단·대표팀 선발을 명령하기.
- 영어 생활 경험을 학업·법규·미국 문화의 완전한 이해로 바꾸기.
- 참고작의 회귀·시스템·대사 리듬·장면 배열을 가져와 주인공의 초기 결핍을 지우기.

## RANGE — 유연하게 둘 범위

POV 전환은 Act/Sub-Act 경계의 기능으로 결정한다. 규칙 설명은 선수의 선택을 바꾸는 순간에 두고, 오프시즌을 법규 교과서로 만들지 않는다. 점수·계약 표는 연구 원장에 보존하고 독서 흐름은 행동과 이해관계로 구성한다. 외부 작품의 평균 문장 길이를 이 작품의 절대 기준으로 이식하지 않는다.

## 적용·갱신 절차

O-15G10에서 세 작품16회차(필드1~5·재벌집1~6·데못죽1~5)를 실제 읽고 [기능 비교](../research/STYLE_FUNCTION_COMPARISON.md)를 추가했다. 전체 딥리드 완료는 아니다. 현재 기초안에 다음 판단을 보강한다.

- 좋은 반응, 개인 기록, 기술 숙련, 코치의 역할 평가는 각각 확인한다. 하나의 성공이 다른 약점이나 등록·계약 조건을 자동 해소하지 않는다.
- 낯선 공간에서는 첫 기준점과 이동 원인을 주고, 충돌·호출 같은 사건이 다음 인물의 도착을 설명하게 한다. 독자가 위치를 추측해야만 행동이 성립하는지 점검한다.
- 상대가 아는 사실과 주인공의 추측을 구별한다. 다른 시점을 보여주는 참고작의 장치를 실존 인물의 비공개 생각을 아는 권한으로 가져오지 않는다.

리디1~5화의 본문 p620개는 언어학적 문장 단위가 아니다. 길이 중앙값이나 대화 시작 기호 수를 이 작품의 절대 문장/대사 규칙으로 채택하지 않는다. 수면을 지우는 성장·타인의 심리 상태 수치화·폭력에 의한 가족/조직 복종은 적용 대상에서 제외한다. 이 변경은 설계 점검 규칙이며 새 원고나 기존 원고에 적용한 실적은0이다.

설계 단계에서는 Context Pack의 POV·권한·정보 출처·금지 항목만 검사한다. 집필이 허용된 뒤에만 실제 문단의 낭독·200자·대사 중복을 검사한다. 참고작은 합법적 본문 열람→기능 관찰→이 작품의 KEEP/ADOPT/AVOID/RANGE 변경 근거 순서로 추가한다. 메타데이터만 확인한 작품에서 문체 결론을 만들지 않는다. G11은 10작품+예비3, 4플랫폼, 기본 1~5화·핵심4작품 6~20화의 독서 근거가 충족되기 전 미완료다.
