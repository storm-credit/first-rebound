# A01 첫 진입 국소 Blueprint — 현행 정본 대조 완료

- 상태: `ACTUAL_VERIFIED` / `CURRENT_CANON_LOCAL_CORE_EVENTS_ONLY`. [원장](A01_OPENING_BLUEPRINT.json)의 4 Beat·5주장·제안 종료 경계를 현행 정본과 대조했고 8개 원본 지문이 일치한다. 공통 writing §22의 현재성 분류이며 **G13 최종 회차·실제 씬 POV·Pack·집필 사용 권위 인증이 아니다**. [검수 기록](../reviews/A01_OPENING_BLUEPRINT_REVIEW_2026_10_04.md)을 함께 읽는다.
- 기능 하나: **숨는 공간이 조건 있는 농구 체험 기회로 바뀐다.** 첫 훈련과 조건 수락은 다음 판단으로 남긴다.
- 배치: `provisional_opening_position=1`, `final_episode_number=null`, `global_episode_assignment_locked=false`. 36슬롯 배분이나 A01 인과후보 12개를 실제 회차 수로 바꾸지 않는다.
- 범위: `canon/STORY_BIBLE.md` **「농구 입문 동기 — LOCKED / 1단계: 체육관 진입」**의 첫 세 항목 및 `canon/PROJECT_FREEZE.md`의 v0.7 현재 입문 인과. A01-S1 질문·S1 스타일 방향·Context 규약은 원장 `derived_from`에 구분했다. 경로별 LF 정규화 SHA256은 `source_rev_sha256`에 기록했다.

| 부분 순서 | Beat — 원본 항목 | 주인공이 알 수 있는 것 / 아직 알 수 없는 것 |
|---|---|---|
| B1 | 출석 경고가 이어지는 가운데 늦게 등교 — Story Bible 1단계 첫째 항목 | 자기 지각과 경고 / 정확 결석 일수·행정 단계는 미정 |
| B2 | 교실을 피하려고 비어 있는 체육관 관중석에 숨음 — 같은 항목 | 자기 회피·선택한 공간 / 감독·교사가 이미 알았다고 단정하지 않음 |
| B3 | 우연한 공 반응을 감독이 관찰 — 둘째 항목 | 자기 공 반응 / 감독의 비공개 평가·속마음은 모름 |
| B4 | 감독이 방과 후 체험 훈련만 제안 — 둘째·셋째 항목 | 전달받은 조건만 앎 / 수락·이행·출결 처분은 미정 |

**전후·비용:** 기존 출석 경고와 늦은 등교, 교실 회피에서 시작한다. 끝은 **조건부 제안을 들은 상태**다. 숨는 동안 교실로 돌아갈 기회를 미루고 기존 출결 문제를 해결하지 못한 것이 현재 직접 비용이다. 방과 후 시간 포기·수업 출석·학업보충 이행을 비용이나 완료 사건으로 선지급하지 않는다. 다음 질문은 주인공이 체험 조건을 받아들이고 실제로 지킬지다.

**권한 경계:** 감독은 우연한 반응을 보고 체험 기회만 제안한다. 선수 선발 보장, 담임·생활지도부의 출결 처리 대행, 기존 불이익 삭제는 없다. 정확 날짜·학교명·행정 절차·회차 분량·학사 인증·감독 내면을 새로 채우지 않는다.

**검토 완료 범위:** 별도 Codex가 원장 4 Beat와 잠긴 원본 항목, 각 주장별 접근 경계, `source_rev_sha256` 현재성, 제안 종료를 대조했다. 실제 씬 구현은 없으므로 `individual_scene_pov_verified=false`를 유지한다. 공통 writing §§21–22의 파일 존재와 실행 권위는 별개다. [Context 규약](../context-packs/README.md)은 전체 회차 기능표·역사 사건 원장 잠금 전 실제 Pack 생성을 허용하지 않는다. 이 산출물은 실제 Context Pack 0개·원고 0개, 설계/원고 `CLOSED`를 유지한다.

재검문: `python tools/check_a01_opening_blueprint.py --self-test`. 검수된 Blueprint 본문 지문과 원본 8개 지문을 함께 비교하므로 정본이나 Blueprint가 바뀌면 재검토가 필요하다. 현재 검사기는 국소 경계/현재성을 확인하며 역사 사실·학교 법적 허가를 인증하지 않는다.
