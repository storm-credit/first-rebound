# Tactical Evolution Map v0.1

- 상태: `FOUNDATION_DRAFT`
- 목적: 시대별 전술 변화가 두 선수의 생존·역할·계약·플레이오프 카운터를 어떻게 바꾸는지 설계
- 원고 게이트: `CLOSED`

## 설계 원칙

전술은 해설용 배경이 아니다. 다음 중 하나를 바꾸지 않으면 구조에서 삭제한다.

- 코트 위 선택
- 출전시간과 라인업
- 감독·동료와의 권한 관계
- 계약·드래프트 평가
- 승패와 다음 카운터

한 Sub-Act에는 핵심 전술 문제 1개만 둔다. 보조 문제는 핵심 선택을 선명하게 할 때만 1개 허용한다.

## 두 선수의 비대칭

| 축 | 주인공 | 라이벌 |
|---|---|---|
| 시작 가치 | 신체·리바운드·전환 | 풋워크·풀업·득점 완성도 |
| 만드는 것 | 팀의 두 번째 기회와 연결 | 첫 번째 수비 붕괴 |
| 초기 약점 | 슈팅 중력·하프코트 판단·세부 수비 규율 | 힘·리바운드 관여·오프볼 효율 |
| NBA 진화 | 스위치형 SF/PF → 스몰볼 5 → 숏롤/세컨드사이드 연결자 | 스코어링 윙 → 1차 창조자 → 오프볼과 플레이오프 카운터를 갖춘 에이스 |
| 결말 기능 | 수비→리바운드→전진→더 나은 패스 | 직접 해결 능력이 있어도 팀 선택을 존중하는 대비축 |

## 과잉 방지

- 모든 유명 전술과 모든 실존 스타를 등장시키지 않는다.
- 한 팀이 리그 전체를 대표한다고 단정하지 않는다.
- 전술 용어를 안다고 미래 농구를 미리 발명하게 하지 않는다.
- 주인공에게 슈팅·패스·수비·핸들 모든 최상급 능력을 동시에 주지 않는다.
- 같은 약점을 정규시즌과 플레이오프에서 이름만 바꿔 반복하지 않는다.
- 전술 장면이 중심 질문과 연결되지 않으면 백스테이지 연구로 내린다.

## 천재성·BQ 연결

전술 단계에서 BQ가 자동 상승한다고 가정하지 않는다. 각 구간의 과제는 `canon/TALENT_BQ_MODEL.md`의 성장 증명 사슬을 통과해야 한다.

- 고교: 순간 공간지각은 보이지만 역할·전술 언어는 낮음
- 프렙: 첫 반응과 제한된 역할을 학습
- NCAA: 두 번째 수비와 약한 쪽을 읽음
- NBA 루키: 속도·피지컬·다중 커버리지 때문에 다시 오판
- 전성기: 시리즈 카운터를 읽고 동료에게 전달·조율

주인공이 특정 전술을 이해했다고 해서 관련 슈팅·핸들·권한까지 한꺼번에 획득하지 않는다.
