## 2. 세 종료안의 실질 비교

각 안은 첫 회차의 출발점 B1을 공유하는 **누적 범위**다. E1은 4 Beat, E2는 6 Beat, E3는 9 Beat까지 포함한다. Beat 수는 회차 수나 원고 길이가 아니다. C2의 리바운드→아웃렛→팀 득점은 한 연속 Beat로 유지한다.

| 비교 기준 | E1: 감독의 조건부 제안 — B1–B4 | E2: 첫 체험과 완패 — B1–B4 + T1–T2 | E3: 첫 기여 — 앞선 6 Beat + C1–C3 |
| --- | --- | --- | --- |
| 상태 변화 — 정본 | 교실 회피의 공간에서 조건 있는 체험 기회를 받는 상태로 바뀐다. 수락·참여는 아직 보이지 않는다. | 체험에 실제 들어가고 동갑의 기술·판단·위치선정 앞에서 완패한다. 농구를 좋아해서 들어간 것은 아니다. | 자존심으로 다음 훈련에 남고 본능적 리바운드·아웃렛으로 팀 득점에 기여한다. 계속할 이유가 라이벌 밖으로 확장된다. |
| 정보 접근 — 정본 경계 | 본인의 지각·회피·공 반응과 전달된 제안까지만 필요하다. 감독 비공개 평가는 인물 지식에 넣지 않는다. | 본인의 참여 동기·완패 경험과 라이벌의 관측 가능한 대응이 추가된다. 정확 비교 형식·대사·상대 속마음은 여전히 미정이다. | 본인 수행·팀 득점 관측·필요하다고 느낀 자기 감정이 추가된다. 전원 신뢰나 구체 칭찬을 증명하지 않는다. |
| 독자 기대 — 편집 추론 | 회피하던 인물이 조건 앞에서 실제로 움직일지 기대를 남긴다. 신체 가능성의 발견과 즉시 선수 선발을 구분해 읽을 여지가 생긴다. | 가능성만으로 동갑을 넘지 못한다는 차이를 먼저 보여 준다. 완패 뒤 다시 나올 이유가 다음 질문이 된다. | 팀 기여까지 먼저 보상한다. 농구를 계속할 이유는 또렷해지지만 제안·완패·첫 기여 사이의 각 전환이 첫 단위 안에 함께 들어간다. |
| 호흡 — 편집 추론 | 지각→숨기→발견→제안의 한 국소 상태 변화를 닫는다. 회피 비용과 새 조건을 한 흐름에서 비교할 수 있다. | 제안 뒤 첫 훈련 진입의 동기와 완패를 연결하는 추가 전환이 필요하다. 제안일과 체험일의 동일 여부는 확정하지 못한다. | 완패 뒤 재방문·잔류와 첫 기여·정착 이유까지 넘어간다. 정본의 패배 다음 날 자발 재방문을 보존해야 하며, 그 재방문과 C1의 정확 대응은 미정이다. |
| 다음 인계 — 기존 사건 | T1: 체육관에 남을 명분과 도발에 반응한 자존심으로 첫 체험에 들어가는 사건을 다음 작업 범위로 넘긴다. | C1: 완패 뒤 자존심으로 다음 훈련에 남는 사건을 넘긴다. | 첫 성공을 근거로 이후 박스아웃·위치선정·패스 학습을 시작하는 방향을 넘긴다. 숙련 완료를 넘기지 않는다. |
| 학교 허가 의존 — 정본 경계 | 제안과 조건 전달까지만 포함하므로 실제 참여 허가·수업/보충 이행을 첫 단위의 완료 조건으로 만들지 않는다. 출결은 별도 권한으로 남는다. | 정본상 실제 첫 훈련 진입은 포함할 수 있다. 그러나 그것만으로 학교 허가나 조건 이행을 완료로 인증할 수 없으므로 전환의 미확인 입력이 단위 내부에 남는다. | 첫 기여까지 포함해도 행정 처리가 자동 완료되지 않는다. 반복 참여의 날짜·허가·보충 이행을 추가 인증하지 않은 채 긴 범위를 다루게 된다. |

**선택 근거 — 편집 추론:** 첫 단위가 보여 줄 변화는 농구 정착 전체가 아니라, 숨으려 고른 공간에서 조건이 붙은 기회를 받는 변화다. E1에서는 이미 발생한 회피 비용과 아직 지불하지 않은 참여 조건을 함께 제시하고, 실제 참여 동기와 완패는 다음 단위가 담당하게 할 수 있다. 이 변화와 종료점이 같은 범위를 닫으므로 E1을 이번 작업 경계로 선택한다. E2·E3의 사건은 삭제하지 않고 뒤의 설계 입력으로 보존한다.

## 3. E1의 구체 구현 범위

### 3.1 시작과 단일 기능

- 입력 상태: **출석 경고가 남은 채 늦게 등교했고 교실에 들어가기를 피한다**
- 이번 작업 회차의 단일 기능: **숨는 공간이 조건 있는 농구 체험 기회로 바뀐다**
- 현재 직접 비용: **관중석에 숨는 동안 교실로 돌아갈 기회를 미루며 기존 출결 문제를 해결하지 못한다**
- 종료 위치: B4의 **조건부 제안이 전달된 지점**. 수락 발언·첫 훈련 참여·완패를 포함하기 전에 끝낸다.

| 순서 / 정확 출처 | 이번 범위에 포함할 사건과 선택 | 직접 비용·압력 | 정보 접근 / 종료 제한 |
| --- | --- | --- | --- |
| 1 — `A01_OPENING_BLUEPRINT.json#B1`, STORY_BIBLE 농구 입문 1단계 첫째 | 출석 경고가 이어지는 가운데 늦게 등교한다. 새 선택이나 징계 수치를 만들지 않는다. | 기존 출결 문제를 해결하지 않은 출발 상태를 남긴다. 추가 처벌 발생을 새 비용으로 넣지 않는다. | 본인의 지각과 받은 경고. 날짜·경고 단계·교사 보고 시점은 미정이다. |

### 3.2 끝에 남는 상태와 기대

종료 상태를 다음 문장으로 식별한다. 이것은 **설계 상태 표기이며 원고 문장/대사 예시가 아니다**.

> 감독의 방과 후 조건부 체험 제안을 들었다. 수락·수업 출석·보충·시간 준수와 실제 출결 처리는 아직 일어나거나 확인되지 않았다

독자에게 남기는 질문은 조건이 있는 기회 앞에서 실제 참여가 어떻게 이어지는가이다. 이후 T1의 참여 사건과 그 동기는 이미 정본에 있으므로 작가에게 수락 여부를 다시 선택하도록 요청하지 않는다. 이 첫 경계에서 아직 보여 주지 않았다는 정보 차이만 남긴다.

S1의 전역 문체·시점 방향을 개별 장면 POV 인증으로 전환하지 않는다. 감독의 관찰은 사건 권위에, 주인공이 실제 아는 내용은 정보 접근 경계에 두어 서로 섞지 않는다. 정확 정보 전달 대사와 형식은 작성하지 않는다.

## 4. 다음 첫 체험으로 넘기는 정확한 입력

| 인계 항목 | 확정 전달 / 미인증 구분 |
| --- | --- |
| 상태 문자열 일치 | E1 종료 상태는 `A01_FIRST_TRIAL_BLUEPRINT.json.entry_state`와 문자 단위로 일치한다. |
| 다음 핵심 사건 — 기존 작가 확정 | T1: 체육관에 남을 명분과 감독의 도발에 반응한 자존심 때문에 첫 훈련에 들어간다. T2: 같은 학년 엘리트 라이벌에게 기술·판단·위치선정으로 완패한다. 새 수락 결정을 요구하지 않는다. |
| 다음 범위의 종료 상태 — 보존 | 체육관에 남을 명분과 자존심으로 첫 훈련에 들어갔고 같은 학년 라이벌에게 기술·판단·위치선정으로 완패했다. 다음 훈련에 남는 행동은 이 단위 밖이다. |
| 다음 직접 비용 — 추론 한계 보존 | 실제 훈련에 쓴 시간에는 과제 없이 머무를 수 없다는 시간 비용과 정본 완패를 구분한다. 특정 게임 약속 취소·정확 소요 시간·수업/보충 완료를 추가하지 않는다. |
| 미인증 입력 1 — 학교 | 첫 훈련 진입이라는 사건은 잠겼지만, 실제 체험 허가·수업 출석·보충 이행·시간 준수·출결 처분은 인증되지 않았다. T1의 존재만으로 이 값을 참으로 바꾸지 않는다. |
| 미인증 입력 2 — 연결 방법 | 명시 수락 발언·도발 대사·조건 확인 절차·제안일과 체험일의 동일 여부·개별 장면 POV는 미정이다. 이 문서는 연결 장면이나 행정 결과를 새로 만들지 않는다. |
| 이후 정본 방향 — 보존 | 완패 뒤 자존심으로 다음 훈련에 남는 C1과 패배 다음 날의 자발 재방문을 유지한다. 재방문과 C1의 정확 대응·정확 달력은 미정이다. 첫 리바운드/아웃렛/팀 득점 C2와 C3 정착 이유는 E1 안으로 당기지 않는다. |

학교 허가 미인증은 이미 잠긴 참여 사건을 취소하는 의미가 아니다. 정본 사건이 있다는 사실과 그 사건을 행정·장면 수준에서 구체 실행할 입력을 인증했다는 주장을 구분한다. 이번 선택으로 그 미인증 입력은 다음 첫 체험 작업에 명시적으로 넘겨졌다.

## 5. 계수와 권위

아래 계수는 **이 문서 한 건의 산출물 종류와 증분**이다. 전체 프로젝트의 완료 개수나 확정 회차 개수를 덮어쓰지 않는다.

boundary_id: A01-E1
status: WORKING_BOUNDARY
editorial_comparison_completed: true
working_boundary_count: 1
actual_final_episode: null
global_assignment: false
G13_final_episode_functions_added: 0
G14_actual_context_packs_added: 0
manuscript_count: 0
manuscript_allowed: false
A01_existing_allocation_slots: 36
A01_allocation_slots_consumed: 0
new_author_locks: 0
author_locked: false

A01의 기존 36개 배분 슬롯과 3소막은 그대로다. E1은 그중 확정 번호 1을 배정한 뜻이 아니다. 전역 배치·G13 최종 기능·G14 실제 Context Pack·원고는 각각 별도 게이트를 따른다.

## 6. 기존 스킬 순서 준수와 국소 자체 검문

기존 공통 writing skill(`novel-writing-skills/skills/writing/SKILL.md`)의 상위→하위 순서를 재사용했다. 이 작업은 **기존 Ending/Act/SubAct의 A01 범위 → 이미 근거 연결된 B1–B4/T1–T2/C1–C3 → 첫 작업 경계 E1 비교·선택 → 아직 만들지 않은 Pack/원고** 순서다. 첫 회차 번호를 먼저 정해 사건을 맞추지 않았고, Blueprint 검증만으로 Pack을 인증하지 않았다. 공통 스킬의 기존 적용 범위와 §§3/7/8/10c/13/19/21/22를 유지하며 새 스킬·모델을 추가하지 않았다.

| 실제 확인한 국소 조건 | 결과 |
| --- | --- |
| 누적 종료안 4 / 6 / 9 Beat와 C2 단일 연속 기능 | 원본 4+2+3 Beat와 대조했다. E1만 이번 경계에 포함한다. |
| B1→B2→B3→B4 순서 | 원본 부분순서와 일치한다. |
| 앞뒤 상태 | opening 종료 = first-trial 입력, first-trial 종료 = first-contribution 입력의 동일성을 읽고 확인했다. |
| 제안과 학교 허가 / 참여 이행의 구분 | E1은 제안에서 끝내며 미인증 값을 다음 입력에 남겼다. |
| 정보 접근 | 감독·라이벌·팀의 비공개 내면을 추가하지 않았다. 개별 장면 POV는 미인증이다. |
| 사건과 비용의 구분 | 이미 발생한 회피 비용만 E1에 넣었다. 참여 조건의 이행 비용과 첫 완패는 다음 범위다. |
| 상위 배분과 최종 회차 | 36슬롯 소모 0, 전역 배정 false, 최종 번호 null이다. |
| 원고·예시 문장·실제 Pack | 0건. 설계 상태 문자열과 사건 표만 기록했다. |
| 도구 실행 | 이 문서 작성 중 Antigravity·NotebookLM·Claude 호출 0회다. 별도 독립 검문 완료로 주장하지 않는다. |

자체 검문은 이 경계 판단의 내용·지문·인계에 한정한다. 전체 설계 게이트나 후대 NBA 결과, 학교 절차, 실제 장면의 독립 검증을 완료했다고 주장하지 않는다.
