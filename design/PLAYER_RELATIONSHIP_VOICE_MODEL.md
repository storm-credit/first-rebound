## 1. 핵심 원칙

기술은 고립된 훈련으로 획득하지 않는다.

`상대가 약점 노출 → 코치가 원인 언어화 → 훈련 담당이 동작 반복 → 동료가 실전 속도로 재검증 → 공식 경기에서 카운터 증명`

한 사람이 약점 발견·전술 설명·개인 훈련·출전 결정·심리 상담을 모두 담당하지 않는다. 관계마다 권한과 비용을 분리한다.

## 2. 실존 우선·가상 최소화

| 기능 | 우선값 | 가상 인물이 필요한 경우 |
|---|---|---|
| 팀 전술·출전 판단 | 당시 실존 감독·코치 | 사용하지 않음 |
| 팀 훈련·영상 | 실존 코칭·영상·선수개발 조직 | 공개 자료로 담당자를 특정할 수 없으면 직함만 사용 |
| 동료의 기술 자극 | 당시 실존 동료 | 공개 농구 범위 밖 사생활·민감 갈등이 필요할 때 분리 |
| 비시즌 캠프·픽업런 | 실제 행사와 검증된 접근 경로 | 특정 개인이 아닌 가상 비공개 세션이 구조상 필수일 때만 |
| 장기 개인 기술 훈련 | 공개된 실제 트레이너가 확인되면 후보 | 반복 사적 대화·갈등·장기 동행을 안전하게 담당 |
| 계약·광고·대표팀 조율 | 가상 에이전트·매니저 | 기존 정본 유지 |
| 인종·가족·사생활 공격 | 가상 상대 | 실존 인물에게 부여 금지 |

목표 비율은 실존 세계 80% 안팎, 가상 연결 인물 20% 안팎의 설계 감각이다. 수치 할당이 아니라 인맥 수집과 허구 사생활을 막는 기준이다.

## 3. 2018 Atlanta 실제 개발 환경 기준선

- Lloyd Pierce는 부임 당시 선수 성장과 신뢰 형성을 강조했고, 2018-19 스태프는 Trae Young·Kevin Huerter·Omari Spellman·John Collins의 개발에 관여했다.
- 당시 코칭스태프에는 Melvin Hunt, Marlon Garnett, Greg Foster, Matt Hill, Chris Jent가 있었다.
- Therian Williams는 2018년에 video operations와 player development 경력이 확인된다.
- 이 사실만으로 특정 코치가 주인공에게 특정 드리블·슛을 개인적으로 장기 지도했다고 단정하지 않는다.

기존 정본의 ‘반복 기술 지도자는 가상 트레이너’ FOUNDATION_LOCK은 유지한다. 먼저 실제 코치의 공개 역할·기술 전문성·접근 기간을 감사하고, 팀 밖 사적 반복훈련에 남는 기능만 가상 트레이너에게 배정한다. 트레이너의 정확한 이름·경력·지도 기술·등장 기간은 HOLD다.

## 5. 비시즌 관계 예산

한 비시즌에 다음을 상한으로 둔다.

- 반복 코치 또는 트레이너 1축
- 그해 핵심 동료 1축
- 실제 접근이 확인된 공개 캠프·픽업런 1축
- 다음 시즌에 약점을 시험할 라이벌·상대 영상 1축

2019 Kobe 접점은 이미 실존 스타 직접 훈련 1축으로 잠겨 있다. 매년 다른 전설에게 기술을 받는 구조는 금지한다.

### 접근 경로 필수값

- 같은 팀·G League assignment·Summer League
- 같은 에이전시 또는 공식 초청
- 공개 캠프·리그·대표팀
- 기존 동료의 구체적 소개
- 구단 승인 시설과 공식 스태프

‘유명해서 만났다’, ‘한국 스타라 초대됐다’만으로 사적 훈련 관계를 만들지 않는다.

## 6. 관계가 기술을 만드는 5단 원장

| 단계 | 기록할 것 | 통과 기준 |
|---|---|---|
| 노출 | 누가 어떤 방법으로 약점을 드러냈는가 | 경기·훈련의 구체적 상황 |
| 저항 | 주인공이 처음에는 무엇을 오해·거부했는가 | 조용한 성격이 무반응으로 축약되지 않음 |
| 교환 | 상대 또는 동료도 무엇을 얻는가 | 일방적 기술 선물 금지 |
| 비용 | 분·신뢰·몸·시간·관계 중 무엇을 잃는가 | 공짜 친분·공짜 성장 금지 |
| 검증 | 같은 관계에서 기술과 신뢰가 어떻게 다시 시험되는가 | 다음 상대 카운터까지 남김 |

## 7. 주인공 말투·트래시 토크

### 평상시

- 말수가 적고 반응이 크지 않다.
- 친구들과는 건조한 농담을 하지만 분위기 메이커가 아니다.
- 권위자에게 무례를 과시하지 않고, 질문이 필요할 때 짧고 구체적으로 묻는다.
- 영어 생활 회화가 가능해도 초반 농구 전술어·미묘한 농담·라커룸 속도에는 빈틈이 있다.

### 승부 상황

트래시 토크의 권장 리듬은 `침묵·행동 70 / 건조한 응수 20 / 선제 도발 10`이다. 이는 대사 수의 기계적 비율이 아니라 캐릭터 붕괴를 막는 장면 예산이다.

- 먼저 장시간 떠들지 않는다.
- 상대가 도발하거나 같은 약점을 반복 공략할 때 짧게 응수한다.
- 성공 뒤 자기 과장보다 방금 실패한 상대의 선택을 확인시키는 방식이다.
- 팀이 위기일 때 평소보다 지시가 늘지만 연설가로 변하지 않는다.
- 약자·벤치 선수·부상자를 조롱하지 않는다.
- 욕설·테크니컬 파울은 빈도와 실제 경기 비용을 기록하며 영웅성으로 미화하지 않는다.

### 경기별 예산 후보

| 경기 | 직접 대사 예산 | 중심 표현 |
|---|---:|---|
| 일반 정규시즌 | 0~1회 | 시선·매치업 재요청·다음 플레이 |
| 오래된 동료와 대결 | 1~2회 | 농담과 역할 기억 |
| 핵심 라이벌전 | 2~4회 | 약점 확인·카운터·승부권 |
| 플레이오프 전환점 | 1~2개의 결정적 교환 | 반복 대사보다 경기 결과 |
| 훈련·픽업런 | 필요 시 더 자주 | 기술 시험과 관계 충돌 |

## 8. 인물별 음성 대비

| 인물 | 어투 기능 | 트래시 토크 방식 |
|---|---|---|
| 주인공 | 짧고 건조한 사실형 | 결과가 나온 뒤 상대 선택을 찌름 |
| 라이벌 | 차분한 분석형 | 주인공이 아직 못하는 것을 정확히 말함 |
| Brunson | 간결한 준비·지시형 | 도발보다 해야 할 일을 확인 |
| Bridges | 반복·기준형 | 말보다 같은 수비 자세를 다시 요구 |
| DiVincenzo | 가까운 또래 농담형 | 실패 뒤 관계를 정상화하는 가벼운 놀림 |
| Trae | 빠르고 표현 많은 전술형 | 수비의 반응을 말과 플레이로 동시에 흔듦 |
| Huerter | 절제된 기술 확인형 | 준비 위치·타이밍의 작은 차이를 지적 |
| Collins | 에너지·역할 주장형 | 골밑 공간과 리바운드 책임을 직접 요구 |
| 가상 적대자 후보 | 노골적 낙인형 | 국적·벤치 경력·과대평가 프레임을 사용하고 실제 비용을 치름 |

실제 인물의 정확한 문장·습관·강도는 공개 인터뷰와 경기 자료를 조사한 뒤 보정한다. 표는 음성 기능 후보이며 실제 사적 발언을 주장하지 않는다.

## 9. 실존 인물 방화벽

- 공개 농구 활동 밖의 사생활·범죄·차별·심각한 모욕을 창작하지 않는다.
- 실제 인용처럼 보이는 문장을 출처 없이 사용하지 않는다.
- 실존 선수의 승리·수상·출전시간을 주인공의 관계 성장 장치로 양도하지 않는다.
- 실존 선수도 주인공 때문에 인격적으로 완성되거나 자동 희생하지 않는다.
- 민감한 갈등이 필요하면 기능이 겹치지 않는 가상 인물로 분리한다.
- 실제 팀 내 권한은 감독·코치·트레이너·의료진·에이전트별로 유지한다.
