# Chicago Franchise Reopen

- 상태: `AUTHOR_SELECTED_DIRECTION / CANON_REOPEN_GATE`
- 기준일: 2026-09-06
- 범위: 주인공 첫 NBA 팀·원클럽 프랜차이즈 경로·동서부 라이벌 구조
- 원고 게이트: `CLOSED`

## 1. 작가 선택

주인공의 장기 NBA 경로는 **Chicago Bulls 원클럽 프랜차이즈 스타**로 전환한다. 라이벌은 서부 콘퍼런스의 별도 프랜차이즈에서 성장한다. O-15E1 작가 선택으로 라이벌의 Minnesota 전체 1순위는 LOCK됐으며 정확 공격형·신인 기록은 별도 `HOLD`다.

이 선택에서 `단독 프랜차이즈`는 2018년부터 기존 간판을 지우는 뜻이 아니다.

- 2018~21: Zach LaVine이 기존 공격 간판, 주인공은 수비·리바운드에서 공격 기능을 확장한다.
- 2021~23 후보: 두 선수가 공동 에이스 구간을 거친다.
- 이후: 주인공이 최우선 코어와 플레이오프 1옵션으로 상승한다.
- LaVine의 실제 성과·분·계약은 자동 이전하지 않는다. 잔류와 정당한 이별을 모두 계산한다.

## 2. 2018 진입점 사실

Chicago는 2018 NBA Draft 전체 22순위로 6피트 7인치 포워드 Chandler Hutchison을 지명했다. 당시 구단 자료도 스몰포워드를 비교적 열린 자리로 평가했다. 따라서 Villanova에서 적은 분을 뛴 장신 수비·리바운드 원석이 워크아웃과 신체 측정으로 22순위 후보가 되는 구조는 가능하다.

그러나 **Chicago 팀 선택과 22순위 확정은 분리한다.** 22순위는 현행 최우선 착지 후보지만 다음 항목 전에는 `NOT_CANON/HOLD`다.

1. 대학 저사용 선수가 22순위까지 오르는 워크아웃·측정·팀 보드 근거
2. 실제 Hutchison의 다음 팀·순번과 22~60 전체 드래프트 보드
3. Chicago 2018-19 player-game donor와 주인공 정확 출전일
4. Windy City 배정의 실제 가능 날짜와 NBA 동시 출전 금지

## 3. 루키 생존 경로 후보

| 단계 | 기능 | 역사 보존선 |
|---|---|---|
| Draft·계약 | 22순위 후보, 1라운드 rookie-scale | 투웨이 계약으로 낮추지 않음 |
| Summer League | 수비·리바운드·전환은 즉시 통함 | 공격 판단·슈팅 약점 유지 |

| 기회 확대 | Valentine 시즌 결장·Holiday 거래 뒤 분 확보 | 부상·거래를 주인공 편의로 새로 만들지 않음 |
| 후반 | 매치업 선발 또는 수비 클로저 실험 | Otto Porter 합류 뒤 자동 주전 금지 |

실제 Hutchison의 44경기·14선발은 관측 가능한 슬롯이지 주인공에게 복사할 기록이 아니다. 실제 부상도 주인공에게 자동 이전하지 않는다.

## 4. Atlanta 정본과의 충돌 처리

v0.15~v0.26의 Atlanta 30순위 착지와 관련 계산은 새 활성 세계선에서는 사용하지 않는다. 삭제하지 않고 **폐기 분기 증거**로 보존한다.

| 기존 축 | 현행 처리 |
|---|---|
| Atlanta 30순위 | `SUPERSEDED_BY_AUTHOR_DIRECTION` |
| Erie 6경기·43경기·621.9분 | `ARCHIVED_BASELINE / NOT_ACTIVE_CANON` |
| Trae·Huerter·Collins 깊은 관계 | `REOPENED` |
| Spellman→Spurs→Metu→Dallas→Spalding→Denver | `REOPENED_FROM_PICK_22` |
| Atlanta 2019~23 계약·Murray·Collins·Huerter 연쇄 | `ARCHIVED_ALTERNATE_BRANCH` |
| Atlanta 공동 프랜차이즈 A1 | `SUPERSEDED_LEAN` |

일반 원칙은 유지한다. 1라운드 표준계약, NBA 본무대, 짧은 G League assignment 가능성, 자기관리 재발의 기능, 실존 선수의 분·성과를 공짜로 가져오지 않는 규칙은 팀 변경과 무관하다.

## 5. Chicago 장기 나비효과 우선순위

| 시점 | 실제 축 | 재계산 질문 |
|---|---|---|
| 2018-19 | Hoiberg→Boylen, Holiday 거래, Otto Porter 영입 | 주인공 분·성장과 감독 교체·거래 동기가 함께 생존하는가 |
| 2019 Draft | 실제 7순위 Coby White | 바뀐 승수·로터리에서 픽과 선수가 유지되는가 |
| 2020 Draft | 실제 4순위 Patrick Williams | 성장한 SF/PF 주인공과 중복되어 다른 선택이 필요한가 |
| 2021.03 | Vučević 거래, Hutchison 포함 거래 | Hutchison 부재와 주인공 성장 뒤 거래 구성·픽 비용이 성립하는가 |
| 2021 여름 | DeRozan·Lonzo·Caruso | DeRozan의 미드포스트·클러치 중복, Lonzo·Caruso의 보완성을 분리하는가 |
| 2021~22 | Markkanen 이탈·LaVine 재계약 | 실존 선수에게 공정한 역할·계약·이별 사유를 주는가 |

현 구조의 최대 blocker는 **2020 Patrick Williams 지명**과 **2021 DeRozan 영입**이다. 두 사건을 실제대로 복사하면 주인공의 포지션과 공격 권한이 과밀해진다.
