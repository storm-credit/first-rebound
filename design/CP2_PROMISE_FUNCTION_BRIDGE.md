## 2. 겹치는 위치의 주기능과 보조기능

새 장면 수나 의무 횟수를 만드는 규칙이 아니다. 아래는 같은 기존 소막에서 여러 약속을 동시에 설명할 위험을 줄이는 우선순위 후보다.

| 기존 위치 | 먼저 보여 줄 기능 | 함께 보이는 비용 | 분리할 것 |
|---|---|---|---|
| A01-S1 (P1/P5) | 준비에 참여하는 자신의 행동 | 팀 기준과 라이벌 방식의 차이 | 라이벌 소개를 모든 후대 갈등의 원인으로 설명하지 않음 |
| A05-S1 (P1/P2) | 이미 발생한 준비 부족의 책임 | 다음 준비에 쓰는 시간과 평가 보호 포기 | 새 책임 행동이 과거 기회 상실의 원인은 아님 |
| A11-S3 (P1/P3) | 미선택 경로의 불리한 판단을 공개 | 공동 공격 권한·평가 부담 | 패배 후보를 실제 패배로 채택하지 않음 |
| A12-S1 (P3/P4) | 사람 유지와 기능 유지를 구분 | 자기 조건과 팀 깊이 | 실제 선수 동의·이적·감액·급여 확정과 분리 |
| A13-S3 (P1/P3) | 더 유리한 동료에게 보내는 마지막 패스 | 자기 슛 기회와 결과 책임 | 고정 결말 승리는 유지. 정확 연도·점수·수신자는 HOLD |

## 3. 침묵 길이를 아직 인증할 수 없는 구간

P2의 마지막 중간 표지는 A05-S1인데 회수는 A14-S3다. A06~A13에 P2 표지가 없으므로 가장 긴 약속 공백을 먼저 의심한다. P1의 A05→A11, P5의 A03→A09도 독자 기억 점검 대상이다. 이는 소막 인덱스의 공백이며, 실제 본문에서 준비/대조 기능이 사라졌다는 증거는 아니다. 780배분 슬롯을 실제 회차 간 침묵 길이로 세지 않는다.

후속 사건/기능표가 선택되면 해당 약속이 현재 행동의 비용을 바꾸는 기존 장면을 먼저 찾는다. 이미 기능이 보이면 새 설명을 넣지 않는다. 실제로 단절됐을 때만 기존 사건의 행동/관계와 연결하는 변주를 제안한다. 구체 회차·허용 침묵 수·추가 사건은 지금 정하지 않는다. 장부의 23개 연결 위치(고유 소막18개)는 실제 본문 회수23건이 아니다.

## 4. 집필 전 전달 조건

사건 채택 후 해당 소막에서 실제로 사용되는 약속만 Context Pack에 담는다. 원고에서는 심기→변형→회수가 선택·대가·보상을 바꾸는지 확인한다. 위 표 존재만으로 G13 회차 기능표/G14 실제Pack/G16 독립 검수/G17 작가 승인을 완료 처리하지 않는다. 기존 원장 PLANNED와 다섯 약속 수는 유지한다.
