- 상태: `PROVISIONAL_FUNCTION_PACKET / NOT_EPISODE_OUTLINE`.
- 기준 main: `5baec34`. Freeze v0.30 PARTIAL, 설계·원고 CLOSED.
- 범위: 기존 A03-S1/S2/S3의 사건 기능을 구체화한다. 54회차 배분을 회차 번호로 잠그지 않는다.
- 재개 근거: [대학 범위 게이트](../control/COLLEGE_ARC_SCOPE_GATE.md)의 전체 Act 실제 사용 조건을 [Act Map](ACT_MAP.md)과 [Sub-Act Map](SUB_ACT_MAP.md)의 A03 배치가 충족한다. 대학 시즌 전체 연구는 재개하지 않는다.
- 권위: 기존 역할·성장 기능은 유지한다. 아래 구체 행동·비용은 설계 후보이며 새 작가확정·역사 사실이 아니다.
- 적용: 공통 novel-writing-skills writing §10b·13·16·22의 선택·비용·회수와 실행 권위 구분.

## 1. 초기 실패 — A03-S1

| 항목 | 기능 후보 |
|---|---|
| 진입 | 프렙에서 통하던 신체 능력을 대학 출전 시간으로 곧바로 환산하려 한다. 기존 주역의 자리는 이미 있다 |
| 문제 | 자신이 상대를 막았다는 결과에 집중하면 팀의 스위치·도움 수비 연결을 놓칠 수 있다. 구체 실패 경기와 포제션은 HOLD |
| 선택 | 즉시 더 많은 분을 요구하는 대신, 자신의 수비 판단이 동료에게 넘긴 부담을 영상 검토에서 확인하고 다음 훈련의 제한 역할을 수락한다 |
| 직접 비용 | 쇼케이스 기회가 늘지 않은 상태에서 영상·학업·역할 훈련 시간을 먼저 지불한다. 실패를 인정했다고 당일 로테이션 복귀를 보상하지 않는다 |
| 종료 | 출전 불만을 없애는 것이 아니라, 다음 기회를 얻기 전에 수행할 수비 과제를 구분한다 |
| 다음 기능 | S2에서 동료가 확인할 수 있는 반복 행동이 필요하다. 말로 반성한 것만으로 신뢰를 얻지 않는다 |

실패를 NCAA 자격 박탈·새 부상·선발 강등으로 확대하지 않는다. 기존 선발 0회 역할과 충돌하는 '주전에서 밀려남'은 사용하지 않는다. 감독의 실제 대사·징계 기록은 발명하지 않는다.

## 2. 역할 획득 — A03-S2

| 항목 | 기능 후보 |
|---|---|
| 진입 | 역할 과제는 알지만, 동료가 경기 중 맡길 정도의 반복 증거는 없다 |
| 문제 | 볼을 받거나 개인 리바운드를 기록하는 행동과 팀에 필요한 위치·박스아웃이 경쟁한다 |
| 선택 | 볼 없는 준비 위치를 지키고 박스아웃을 먼저 수행해 동료가 공을 확보하게 한다. 공격에서도 사용률을 올리기보다 지정된 연결을 반복한다 |
| 직접 비용 | 박스아웃 성공이 자신의 리바운드 숫자로 남지 않을 수 있고, 개인 공격 표본도 제한된다. 남은 훈련 시간과 학업 의무는 사라지지 않는다 |
| 종료 | 한 번의 칭찬이 아니라 반복된 과제 수행이 제한된 수비 기능을 맡길 근거가 된다. 정확한 출전 상승 경기·분은 HOLD |
| 다음 기능 | 토너먼트 압박에서도 같은 기준을 지키는지 S3에서 시험한다 |

Brunson·Bridges·DiVincenzo는 기존 관계 기능의 범위에서만 사용한다. 세 사람 모두를 새 멘토 사건으로 늘리지 않는다. 동료의 실제 발언·개인 감정·위임 포제션은 확정하지 않는다. P2 준비의 기존 A03-S2 연결을 사용하며 새 약속 수를 추가하지 않는다.
