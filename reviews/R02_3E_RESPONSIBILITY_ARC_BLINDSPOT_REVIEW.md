# R02-3E Responsibility Arc Blindspot Review

- 대상: 무목표·출석 붕괴 → 자기관리·팀 책임 성장축
- 판정: `PASS_WITH_EVENT_DETAIL_HOLDS`
- 원고 게이트: `CLOSED`
- R16 독립 검수 대체: `false`

## 핵심 판정

‘농구하면서 정신 차린다’는 방향은 유효하다. 주인공의 기본 성격은 조용한 저에너지·회피형으로 두고, 정신을 차린다는 말을 외향화나 생활 완치가 아니라 **팀이 계산에 넣을 수 있는 신뢰성 획득**으로 정의해야 한다.

## 맹점과 통제

| 맹점 | 실패 형태 | 통제 |
|---|---|---|
| 스포츠 만능치료 | 첫 리바운드 뒤 결석·게임·무기력 즉시 소멸 | 한국 고교→프렙→대학→NBA의 단계별 변화와 재발 유지 |
| 성격 평탄화 | 조용한 저에너지 인물이 농구 뒤 말 많은 분위기 메이커로 변함 | 조용함은 보존하고 필요한 순간의 소통·출석·준비·책임만 변화 |
| 게임 악역화 | 농구를 위해 게임을 버리는 교화물 | 게임은 취미로 유지하고 의무 뒤로 순서만 조절 |
| 상시 허세 피로 | 실력도 없는데 매 장면 천재라고 떠들고 상대를 도발 | 허세는 자존심이 긁힌 순간의 짧은 방어 반응으로 제한 |
| 감동 연설 치트 | 감독·브런슨·코비 한마디로 각성 | 실패→비용→반복→행동 증거 사슬 사용 |
| BQ와 인격 혼동 | 전술을 읽으니 생활도 자동 관리 | 농구 판단과 자기관리 증거를 별도 원장으로 검증 |
| 대학 우승 조기 완성 | 우승 뒤 성장 문제가 사라짐 | NBA 신인기 짧은 자만·재발과 자율 루틴 재확립 |
| 실존 인물 사적 교화 | 브런슨·코비의 허구 명언·비공개 사생활 | 공개 농구 활동과 주인공의 관찰·선택 기능만 사용 |
| 학업 문제 증발 | 농구를 잘하자 성적·자격 자동 해결 | 최소 의무·도움 요청·기한 준수로만 성장 |
| 라이벌 의존 | 라이벌을 이긴 뒤 동기 종료 | 자존심→팀의 필요→자기 기준으로 동기 이전 |
| 승리만 보상 | 이기면 성숙, 지면 퇴행 | 출전하지 않아도 준비하고 역할을 지키는 행동 포함 |

## 단계 통과 테스트

| 단계 | 통과 질문 | 실패 판정 |
|---|---|---|
| 한국 고교 | 패배 다음 날 스스로 나타나는가? | 감독이 잡아와야만 출석 |
| 미국 프렙 | 아무도 깨우지 않아도 의무 순서를 지키는가? | 벌이 있을 때만 움직임 |
| Villanova | 출전시간이 적어도 스카우팅과 역할을 준비하는가? | 공을 많이 잡을 때만 헌신 |
| NBA | 학교 규칙 없이도 자기 루틴을 유지하는가? | 코치·트레이너가 관리해줘야만 준비 |
| 결말 | 인정과 영웅 슛보다 더 나은 팀 선택을 하는가? | 직접 끝내야만 책임이라고 믿음 |

## 과밀 방지

책임 성장을 설명하는 핵심 인물은 새로 늘리지 않는다.

- 성격 표면: 평소 조용함, 친한 친구와 건조한 농담, 승부에서만 짧게 점화
- 한국 고교: 감독·동갑 라이벌·팀
- 미국 프렙: 프렙 코치와 기존 경쟁자 슬롯
- Villanova: Brunson·Bridges·DiVincenzo
- NBA: 기존 감독·핵심 동료·가상 스킬 트레이너
- Kobe 접점: 반복 훈련 방식 확인 1회

각 단계에 별도의 생활 멘토를 추가하지 않는다.

## 남은 HOLD

- 프렙에서 잃는 실제 기회와 권한 주체
- Villanova에서 역할 이탈로 신뢰를 잃는 경기
- 토너먼트 대표 책임 행동
- NBA 신인기 재발과 계약·배정 비용
- 단계별 정확한 회차·장면 배열

## 판정

성격 보존과 신뢰성 성장을 분리한 현재 구조는 주인공의 무목표 출발, Villanova 팀 우승, 장기 결말의 패스 선택을 하나의 축으로 연결한다. 세부 사건은 NCAA 자격·로테이션·NBA 계약 검증 전까지 HOLD한다.
