# R01 O-15F14-Q — F4/F5 선택 브리지의 문서 단독 반증

- 입력: `simulation/CHICAGO_2020_21_F4_F5_SELECTED_BRIDGE.md` 초안만 Claude CLI `haiku --tools '' --max-turns 1`에 제공했다. 최초 저장소 읽기 시도는 장시간 출력 없이 종료했으며 검증으로 세지 않는다. 두 번째 무도구 검토는 답변을 받았다.
- 범위: 문서 단독 내부 논리 점검이다. Claude는 NBA 원문·저장소·계산 JSON에 접근하지 않았으므로 출처 독립 검증이나 G16 검수가 아니다.

| 반증 지적 | 처리 |
|---|---|
| Hall 4월 계약 유형과 5/9 자리 감소 원인이 불명확 | **표현 수용.** 4/13~5/1 일반계약, 5/2 해제, 5/2~8 공백, 5/9 새 일반계약이라는 기존 등록 원장을 브리지에 적었다. 4월 계약이 일반계약이면 5/9 자리 수가 안 바뀐다는 반론은 **시점 간 다른 선수의 자리 채움**을 누락해 계산 반례가 아니다. |
| K1 승수가 그대로라는 주장에 재계산 경로가 없음 | **설명 수용.** 30경기 각각의 선수 초를 치환하고 RAPTOR/BPM 점수차 방향을 다시 계산했으며 다른 1,050경기를 그대로 두는 **국소 가정**을 문서에 명시했다. 후속 건강·평점 변화까지 증명한 것은 아니다. |
| Cleveland 전체 명단·급여·플레이오프 미검증 | **HOLD 유지.** 현재 14경기 5인조는 조건부 역할로 새 LP 증인 14/14를 만들었으나 Cleveland의 전체 기간·다른 경기·계약 부담을 닫지 않았다. |
| Hall 4월 보유와 5/9 생략의 시간 모순 가능성 | **기존 원장으로 해소.** 5/2 해제 이후 공백이 명시돼 있다. 5/9 새 계약을 생략해도 이전 출전은 유지된다. |

Claude는 제공 문서만으로 수치 모순을 찾지 못했다. 마지막 SessionEnd hook 실패는 검토 본문 반환 뒤 발생했으므로, 검토 결과와 원문 접속 여부를 혼동하지 않는다. `F1~F5 0/5`, `A1~A3 0/3`, K 종료 `0/4`; 프로젝트 freeze와 설계/원고 게이트는 그대로다.
