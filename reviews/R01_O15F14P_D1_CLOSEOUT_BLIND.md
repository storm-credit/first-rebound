# R01 — O-15F14-P D1 종료 묶음 문서 단독 반증

[종료 묶음](../simulation/CHICAGO_2020_21_D1_CLOSEOUT_BATCH.md) 초안을 Claude Haiku CLI에 **문서만** 전달했다. F1~F5 근거 문서·NBA/CBA 원문·웹 접근은 제공하지 않았다. 따라서 이는 독립적인 사실 인증이 아니라 게이트·조건부 승인 표현의 논리 검토다.

| 지적 | 처리 |
|---|---|
| `HOLD`가 종료인지 불명확하고 조사 중지선이 게이트를 몰래 면제할 수 있음 | 수용. `PASS/HOLD/FAIL` 정의와 `HOLD`가 열린 상태이며 D1 종료를 막는다는 규칙을 추가했다. |
| CP2 잠정 결과가 F 경로 실패 뒤에도 최종처럼 남을 수 있음 | 수용. CP2는 계속 잠정이며 실패한 입력의 영향을 받은 후손만 재계산하도록 명시했다. |
| F4가 실재하지 않는 대체 세계 리그 문서 원본을 요구하는 것처럼 보임 | 수용. 공개 역사에서 §6.08 요건을 대조하고, A1 건강 달력과 A2 행정 사건을 대체 세계 후보로 구성하되 승인 전까지 HOLD로 두는 순서를 명시했다. |
| A1~A3 선택 방식과 D1 종료 조건이 흐림 | 수용. 기존 K 달력·L1~L4·Hall 자리/대안 권위를 연결하고, F 경로→A 선택→추첨/자산 검증→네 K PASS 순서를 명시했다. |
| F1~F5 계약 검증과 A 선택이 순환한다는 지적 | 기각. F는 제안 경로의 계약·규정 사실/산술을 시험하고 A는 통과한 경로의 작품 사건을 최종 선택한다. 초안에 이 분리가 덜 명시돼 보강했다. |
| F1·F3·F5가 기존 수치·보호 분기를 사실로 단정했다는 지적 | 범위 정정. 해당 수치는 분야별 원장의 조건부 시험이다. 선행 1R 전달/전환 두 분기를 명시하고 각 팀 여유를 서로 더하지 않는 문장을 보존했다. |

이번 묶음은 새 외부 사실을 조사하지 않은 **저장소 통합**이다. Antigravity·NotebookLM의 기존 원문 읽기를 새 독립 근거로 재계수하지 않는다. 신규 작가확정 0건, `PROJECT_FREEZE v0.30 PARTIAL`, 설계/원고 `CLOSED`.
