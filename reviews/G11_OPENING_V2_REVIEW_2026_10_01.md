## NotebookLM: 응답의 적용과 교정

Notebook `303ffd55-e019-476a-9ae3-8dc0e32fe11f`, 새 출처 `b2fe3589-e22d-4065-80dd-3821cbaa10b0`, 대화 `b1305481-c5bc-4b55-9e0b-4c7f34c4bede`. [입력](G11_OPENING_METHOD_REVIEW_INPUT_2026_10_01.md)은 원문 없는 Codex 파생 패킷이다. [응답](G11_OPENING_NOTEBOOKLM_2026_10_01.json)의 sources_used와 참조4개는 모두 같은 출처1개다.

선정 묶음은 전수 밀도/고유 인물 수를 증명하지 않고, 자동 경계는 문법적 문장 수를 증명하지 않으며, 구성요소5/50은 전체 P3 완료가 아니라는 출처 연결 설명을 채택한다.

다음 응답 표현은 입력/실제 JSON과 대조해 채택하지 않았다.

- 위치1075를 “첫1000 안의 위치”라는 일반 설명에 섞었다. 실제로 본문1075는 첫1000 밖이며 prefix는 null이다.
- 묶음 설명에서 회상/계획과 인접 행동을 한데 표현했다. 현재 실행 행동 묶음은 회상된 과거와 미래 계획을 제외한다. 과거/장면 밖 인물 지시나 설명과 구분한다.
- 모든 파생 계측을 “local coder interpretation”에 묶었다. 정규화 문자 수/위치/기계 경계 분포는 기계 계측이고, 기능 묶음은 수동 해석이다.

## Claude 반증: 적용과 기각

[방법 반증](G11_OPENING_CLAUDE_2026_10_01.json)은 38.315초·종료코드0·nonempty result, session `055f7067-b3f0-4288-95fa-6afd3ec7b27f`다. [제한 source-blind 결과 검토](G11_OPENING_SOURCE_BLIND_2026_10_01.json)는 17.198초·종료코드0·nonempty result, session `1dd7f777-4aa8-445f-8c1c-c2526eae3db8`다. 둘 다 원문·외부 도구 접근은 없었다. 후자는 선행 검토를 받지 않았지만 같은 모델 계열의 파생 결과 검토이며 독립 원문 검수로 세지 않는다.

반영:

- 표 머리글에 **첫 DOM p 길이(UTF16)**와 **선정 코딩 수**를 유지하고, 사람 지시 묶음 셀마다 고유 인원 null을 병기했다.
- 비전수 묶음에는 전수 분모가 없으므로 비율/회차 간 밀도·활동량 순위/대표 문체를 산출하지 않는다.
- 실제 언어 문장 수 null, UI/침묵을 포함한 자동 경계 조각과 DOM 경계 영향, 첫1000의 LF·잘림을 명시한다.
- 같은 환경/같은 분류표의 지문 일치는 재현 근거이며 독립 의미 인증이 아니다.

채택하지 않은 확대:

- 좁은 방법 입력에 빠진 정규화/UTF16/국소 코딩 규칙을 Claude가 “미보고”라고 지적했다. 전체 JSON/관측 MD에는 이미 있어 새 수치 오류로 기록하지 않는다. 독립 의미 신뢰도 미검증은 사실로 유지한다.
- “rates or nothing”은 비전수 의미 묶음에 새 비율을 붙일 근거가 아니다. 기계 분포는 실행별 사례 기록으로 보존하고 문체 순위로 사용하지 않는다.
- source-blind 응답의 `≥` 하한 표기는 묶음 단위를 안정된 원자 단위로 오인시킬 수 있어 적용하지 않는다. “선정 코딩 수”로 표시한다.
- 사전에 없는 문자열은 미검색이다. 사전에 있는 문자열의 prefix null과 본문 literal 검색 결과도 구분한다. 어떤 경우도 작품 전체 의미 부재로 확장하지 않는다.
- source-blind 응답이 모든 숫자를 extractor 산출이라고 표현한 것은 수동 의미 코딩에는 맞지 않는다. 기계 계측과 해석의 구분을 유지한다.

이 반영은 모델 응답 **후** Codex가 수행했다. 모델이 수정 표를 다시 읽거나 승인했다고 주장하지 않는다.
