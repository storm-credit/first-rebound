# O-15G15K 결과물 단독 맹점 검수

- 입력: 이전 조사·추천 이유·R01을 제외하고 ‘Aminu 옵션 행사 작업상 우선 후보, Vučević 잔류 승인 범위, O15A 16명/O15C 17명, waiver 보호급여’라는 **결과 요약과 고정 제약**만 새 Claude CLI 세션에 제공했다. 첫 시도는 `max turns`로 실패했고, 두 번째 `haiku / max-turns 3` 호출에서 편집 의심 4건이 반환됐다. 종료 훅 오류는 있었지만 응답 본문은 확보했다.
- 상태: `SOURCE_BLIND_EDITORIAL_RUN / NOT_FACT_CHECK / NOT_G16_PASS`. 이 검수는 다른 원자료를 찾은 독립 NBA 검증이 아니다.

| 결과만 본 편집자의 의심 | 판정과 조치 |
|---|---|
| Vučević의 ‘2020–21까지만 승인’이 계약 종료처럼 보인다 | **수용.** [T2](../canon/CHICAGO_2020_21_DIRECTION_APPROVAL.json)는 **설계 승인 범위**다. 시즌말 계약이 종료되는 사건이 아니므로 G15K 첫 문단에 구분했다. 2021–22 소유는 여전히 후속 거래 여부가 필요하다. |
| Aminu 옵션이 선수의 능동적 선택 없이 자동 발생하는 듯하다 | **수용.** G15K에 선택·통지 사건을 별도로 쓰고 공식 통지일·계약 마감 조항을 null로 유지했다. 원역사 행사 결과를 대체 Orlando의 행위로 복사하지 않는다. |
| 방출 뒤 보호급여가 왜 남는지 불명확하다 | **표현 보강.** [G15I](../research/O15G15I_AMINU_WAIVER_CAP_COST.md)의 [NBA CBA 101 `I.L`·`I.U`](https://cdn.nba.com/manage/2021/03/2018-19-CBA.pdf)로 연결했다. waiver가 자리에는 영향을 주지만 보호급여·cap stretch는 별도다. 검수자의 ‘특별 예외가 필요한가’라는 암시는 원문 근거 없이 채택하지 않는다. |
| 16/17명이 어디서 생겼는지 결과만으로 보이지 않는다 | **수용.** [G15E](../research/O15G15E_ORLANDO_STANDARD_SLOT_BRIDGE.md)의 공통 가능 표준11+대체5=16, 여기에 Gravett 표준1=17, 투웨이 제외를 G15K에 직접 명시했다. 한 자리 처분만으로 O15C는 미해결이다. |

편집 의심은 문서 설명과 다음 조사 질문을 개선했지만, 실제 옵션 통지·waiver 완료·서명·의료·선수 역할을 증명하지 않는다. G14 ORL4/DET4, G16/G17, 시즌·원고 게이트의 상태는 바꾸지 않는다.
