# E5 공동 준비 회차 기능 검문

## 판정과 범위

2026-10-07 root는 [선택된 CF08 일상 설계](../design/A01_CF08_TEAM_PREPARATION_WORKING_MODEL_2026_10_07.md)와 [E5 기능](../design/A01_E5_FINAL_EPISODE_FUNCTION.md)을 국소 수용했다. 기존 팀 준비 방향 안에서 공 준비 몫을 맡고 다음 허용 기회에 수행하는 구현이다. 새 작가 잠금·실제 학교 기록·전체 G13 완료 판정은 아니다.

E4의 전체 종료 상태를 그대로 받아 P1에서 한 동료의 공 준비 부담을 직접 보고, P2에서 자기 몫을 수행한 뒤 그 동료가 남은 몫만 옮기는 행동을 관측한다. 마음을 읽거나 팀 전원의 신뢰로 확대하지 않는다. 두 준비 기회 각각 가상 출석·학업보충·시간준수 조건을 다시 확인한다. CF09 게임 보상 갈등은 이 기능에서 실행하지 않는다.

## 검증 기록

- g11 구현·root 직접 원천/결과물 대조·chi 별도 검문으로 역할을 나눴다. chi는 실제 sourceSHA 6개, Markdown 동기화, E4 전체 입력과 다음 CF09 전체 인계를 확인했다.
- CF08 자체 음성 13개와 실제 원천 cause 반전 포함 독립 변조 검문을 통과했다. 같은 ID를 유지한 채 원인의 뜻을 바꾸던 결함은 원인 고정 비교로 수정했다.
- E5 자체 음성 10개 및 독립 결과물 6개·상위 원천 2개 변조를 거부했다. 원천 현재성·좁은 Blueprint 권위·팀 부담·학교 조건·전체 게이트 허위 승격을 검문했다.
- root는 등록 뒤 E1→학교 모델→E2→후속 학교 모델→E3→학습 경계→CF07→E4→CF08→E5 순으로 현재성을 갱신했다. 기존 국소 Blueprint 3개의 원천 지문을 제외한 의미 투영 SHA는 그대로다.
- CP2 회차 등록 검증 및 기존 의미 검증 17개가 통과했다. 기능 수와 실제 검증 경로 수·연속 슬롯을 대조한다.
- 이번 국소 일상 설계에 새 외부 역사 원자료나 Antigravity/NotebookLM/Claude 실행을 추가하지 않았다. 직전 E4의 각 도구 실행 기록을 이번 E5의 실행으로 다시 세지 않는다.

## 현행 계수와 다음 작업

최종 기능 5개, A01 계획 36슬롯 중 남은 31, 전체 780 계획 배분 중 미배정 775다. 이는 출판 회차 수 확정이 아니다. 실제 Context Pack 0·원고 0, 법적 11 PASS/1 HOLD·F4/5·A0/3·K0/4, 미완료 큰 묶음 6개다. `PROJECT_FREEZE v0.30 PARTIAL`·설계/원고 `CLOSED`를 유지한다.

다음은 E5 전체 종료 상태에서 게임의 즉시 보상과 맡은 준비의 충돌을 좁게 설계·검문하는 CF09 후속이다. GSW의 남은 날짜별 비용 범위 검문은 별도로 계속하며 거래 선택이나 수락을 추정하지 않는다.
