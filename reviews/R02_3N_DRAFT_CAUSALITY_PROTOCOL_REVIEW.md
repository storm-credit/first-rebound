## 맹점 검토

| 맹점 | 잘못된 처리 | 통제 |
|---|---|---|
| 역사 보존 편향 | 유명 선수의 팀을 지키려고 승수·순위를 무시 | 입력이 바뀌면 로터리·보호픽·보드도 재계산 |
| 과대 나비효과 | 주인공 등장만으로 과거 1~29순위까지 변경 | 시간상 선행 사건은 입력 변화가 없으면 유지 |
| 기계적 도미노 | 모든 선수를 한 순번씩 이동 | 각 팀이 남은 보드와 필요로 재선택 |
| 로터리 작가 선택 | 원하는 팀이 나올 때까지 재추첨 | 공개 고정 seed를 결과 전에 잠금 |
| 실제 추첨 강제 | 시드가 바뀌었는데 실제 순번 복사 | 참가팀·시드·확률 변화 시 재추첨 |
| 보호픽 누락 | 실제 양도 결과만 복사 | 보호·스왑·전환 조건을 연도별 원장화 |
| 실존 선수 삭제 | 밀린 선수를 세계에서 제거 | 미지명·투웨이·캠프·해외까지 후속 경로 기록 |
| 라이벌 순번 강제 | 1순위급 평가를 실제 1순위와 동일시 | 팀 필요·의료·팬데믹을 거쳐 실제 순번 결정 |

## 판정 이유

- 사용자가 요구한 `바뀐 승패가 드래프트까지 합리적으로 이어지는 세계선`을 충족한다.
- 역사 보존과 무제한 나비효과 사이에 인과 경계를 둔다.
- 결과를 아직 만들지 않고 방법과 seed를 먼저 잠가 선택 편향을 막는다.
- 원고 게이트는 계속 `CLOSED`다.
