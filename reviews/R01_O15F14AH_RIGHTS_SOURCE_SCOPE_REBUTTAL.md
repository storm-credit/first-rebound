# O-15F14-AH — Claude 문서 단독 반증 수용 기록

- 2026-09-28, Claude CLI `haiku`, 읽기 전용 `Read`로 AH·AF 두 문서를 검사했다.
- 범위는 **문서 논리**다. Claude가 PDF/CBA/NBA 원문을 독립 조회하거나 실제 팀 cap sheet를 인증한 것은 아니다.

| 지적 | 처리 |
|---|---|
| AH의 2006–20 표가 전체 연도 전수처럼 읽힌다 | **수용.** 섹션 제목을 `일부 1라운드 권리 줄`로 바꾸고 2006–10 행도 특정 사건만 확인했다고 명시했다. 2007–09 등 전체 권리 대조는 HOLD. |
| Diebler 2라운드 권리 누락을 1라운드 권리 누락의 직접 증거로 쓰지 말라 | **수용.** AH·AF는 가이드의 자산 목록 완전성에 관한 반례로만 사용한다. Diebler의 1R hold/TPE charge는 주장하지 않는다. |
| CBA §4(e)(2) 해외 계약·(3) 서면 제외의 실제 발생을 확인하지 않았다 | **수용.** 규칙만 확인됐고 실제 Chicago 사건은 미확인; `UNSIGNED_FIRSTS=null` 유지. |
| AF가 2019-02-06을 선수 계약 없는 거래로 취급한다 | **기각.** AF는 Parker·Portis 계약을 Chicago가 **송출**하고 Porter 계약을 받은 사실을 명시한다. 선수 계약 없는 수취 거래로 구분한 것은 **2019-07-07 Satoransky 거래**다. 이 비판은 두 사건을 혼동했다. |
| 기존 TPE 0이 곧 cap charge 0이라는 주장 | **해당 없음.** AF는 DPE와 `EXCEPTION_HISTORY` 전체를 미확정으로 남기고, §6(m)(2)의 산입도 AE 급여 하한·코로나 수정 규칙이 유지될 때만 조건부 0으로 표시한다. |
