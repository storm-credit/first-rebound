# F5 미거래의 정규시즌 누락 4팀분 독립 검문

**대상:** `tools/build_2020_21_selected_regular_overlay.py`의 `complete_f5_source_branches`, 현재 `simulation/NBA_2020_21_SELECTED_REGULAR_OVERLAY.json`. 이 문서는 작업 모델의 원천·산술 검문이며 실제 선수 건강·등록·박스스코어 인증이 아니다.

| 경기·팀 | 역사거래 잔재 제거 → 미거래 잔류 선수 | 초 |
| --- | --- | ---: |
| 2021-04-09 DEN–SAS / DEN | McGee → Hartenstein | 579 |
| 2021-04-28 DEN–NOP / DEN | McGee → Hartenstein | 691 |
| 2021-04-17 CHI–CLE / CLE | Hartenstein → McGee | 962 |
| 2021-04-21 CLE–CHI / CLE | Hartenstein → McGee | 973 |

기존 `main`의 2,160팀분과 새 산출물을 독립 비교하면 선수 초 벡터가 달라진 행은 정확히 위 네 개다. 각 행은 지정된 선수 한 명의 초만 동일량 치환하고 나머지 선수 초, 선발 5명, 경기시간을 보존한다. 네 행 모두 선수 초 합계가 경기시간×5이고 각 선수 초가 경기시간 이내다. 새 5인조 증인을 독립 누적했을 때 모든 양수 선수 초와 경기시간이 복원되고 선발 5인 조합의 180초 증인도 있다.

`main`과 현재 산출물의 1,080경기 승자를 전수 비교한 결과 **변경 0**, 미결정 승자 0이다. 생성기 `--check`도 64개 오버레이 팀분/62경기, 전체 재계산 1,080경기/2,160팀분, 변경 승자·미결정 승자 0으로 통과했다. 원래 60팀분/58경기에서 이번 네 행이 더해졌다.

원천 보호는 실제 음성검문으로 확인했다. 기본 결합 입력의 한 경기에서 선수 두 명의 초를 +1/−1로 바꿔 팀 합계를 보존한 메모리 입력은 `base_check.validate()`의 형식 검사는 통과했지만 `validate_against_sources()`와 이를 호출하는 최종 오버레이 `build()`에서 모두 거부됐다. 따라서 합계만 맞춘 원천 벡터 변조를 새 SHA로 합법화할 수 없다. F5 생략 방향·네 키 집합·완전 벡터·선발/5인조·승자 재계산의 범위만 수용한다.

**한계:** 이 초 배정과 5인조는 위임된 가상 감독 작업 모델이다. 실제 교대 순서, 의료 가용성, 공식 등록, 실제 경기 결과·점수, 최종 시즌 확정은 이 검문으로 증명되지 않는다. 원고 허가도 없다.
