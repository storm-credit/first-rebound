## 출처가 허용하는 판정

- **사실 / 원역사:** NBA 보고서 2쪽은 ORL의 Michael Carter-Williams, Markelle Fultz, R.J. Hampton, Gary Harris, Jonathan Isaac, E'Twaun Moore, Terrence Ross 7명을 `Out`으로 기재한다. 보고서 시점은 2022-01-23 17:30 ET다.
- **추론 금지:** Herbert Jones 또는 Hassani Gravett가 보고서에 없다는 것만으로 그날 ORL 등록, 계약, 활동 가능, 12분 주가드 수행은 증명되지 않는다. 실제 ORL 결장자 기록을 가상 세계 명단에 그대로 합치지도 않는다.
- **후보 / HOLD:** O15A Herbert PG12는 대체 세계의 2021 여름~당일 등록·가용성과 NBA 주전개 역할·수비/공간 비용을 더 확인해야 한다. O15C Gravett PG12는 당일까지의 **새** 적법 계약·자리/급여·등록·활동 증거가 필요하다. 실제 2021-12-17 단기 계약은 당일 계약 지속의 증명이 아니다.
- **모델 출력 교정:** NotebookLM은 가상 경기 후보의 “12분 보장 기록/박스스코어”를 요구했다. 아직 실행되지 않은 가상 경기에는 그런 원역사 기록이 없으므로 이 제안은 채택하지 않는다. 필요한 것은 당시 적용 가능한 계약·등록 규정 및 조건부 240분·역할 비용 검산이다.

이 시범은 새 사실로 G14의 `ROLE_HOLD`를 풀지 않는다. Anti-Gravity CLI의 사용자 로그인 상태를 복구한 뒤 제한된 공식 URL의 결과를 다시 받아야 한다. NotebookLM에는 기사 URL이 읽히지 않았으므로 공식 계약 발표의 원문 확인 후 해당 증거만 보충한다. Claude와 source-blind 독립 검수는 `NOT_RUN`, G16/G17을 대체하지 않는다. `PROJECT_FREEZE v0.30 PARTIAL`, 설계/원고 `CLOSED`, `author_locked=false`, `season_selected=false`, `exact_execution_cleared=false`, `manuscript_allowed=false`를 유지한다.

## 로그인 복구 후속 실행

Anti-Gravity CLI 로그인은 복구됐다. 공식 NBA 기사 두 건은 본문 접근 불가였고, PDF·통계 페이지도 도구가 저장한 파일을 분석하지 못했다. CLI의 URL 기반 날짜·계약 추정은 기각한다. NotebookLM에는 공식 Orlando 미디어 가이드의 거래 연표 한 쪽을 추가하고 출처 인용 분석을 다시 실행했다. [원자료 판독·도구 오류·남은 계약 HOLD](../research/O15G15C_ORLANDO_CONTRACT_CHRONOLOGY.md)에 상세 기록한다. 현재 표시는 Anti-Gravity `RUN / NO_VERIFIED_EVIDENCE_PACK`, NotebookLM `RUN / THREE_SOURCES_WITH_CORRECTIONS`이며 Claude/source-blind는 `NOT_RUN`이다.

## Anti-Gravity MCP/URL 재시험 — 2026-09-26

사용자가 제공한 [공식 CLI 제품 페이지](https://antigravity.google/product/antigravity-cli/)와 [MCP 안내](https://antigravity.google/docs/mcp)를 확인했다. 공식 설명의 `/mcp`와 로컬 `agy mcp list`는 **Anti-Gravity가 외부 MCP 서버를 연결하는 클라이언트 기능**이다. 이 설치본의 `agy --help`에는 Anti-Gravity 에이전트를 MCP 서버로 내보내는 하위 명령이 없고, 현재 Codex MCP 목록에도 Anti-Gravity 서버 등록이 없다. 이를 제품 전체에 서버 기능이 절대 없다는 주장으로 확대하지 않는다.

**실행 경로 교정:** Codex에서 `agy` 단축 명령만 검색한 결과는 설치 여부의 판정 근거가 아니다. `C:\Users\Storm Credit\AppData\Local\agy\bin\agy.exe`의 `--version`은 `1.2.11`을 반환했고 `models`는 서비스 모델 목록을 정상 조회했다. 따라서 **Codex → Anti-Gravity CLI 직접 호출은 작동**한다. 사용자 확인 기준으로 Anti-Gravity에는 Codex·NotebookLM·프로젝트별 Obsidian MCP 설정이 있으나, 설정 확인만으로 각각의 실제 통신을 통과 처리하지 않는다. 아래 재시험에서 통신까지 입증된 것은 **Anti-Gravity → NotebookLM MCP**이다.

| 경로 | 재시험 결과 | 증거 계보와 한계 |
|---|---|---|
| `agy` → NotebookLM MCP | 등록된 `notebooklm-mcp`를 통해 비정본 작업실의 제목 조회 성공. `stream-json` 도구 기록에서 `call_mcp_tool` 완료를 확인 | 연결·호출 **PASS**. NotebookLM 기존 자료를 읽는 경로이며 독립 NBA 원자료 수집은 아님 |
| `agy` → NotebookLM MCP의 NBA 규칙 출처 | 기존 소스 ID `83d42bb0-1786-4552-b0a4-76b95f37b8bf`에서 [NBA Communications 2021–22 규칙](https://pr.nba.com/nba-board-of-governors-play-in-roster-rules-2021-22-season/)의 표준 15명+투웨이 2명 조항과 원 URL 회수 | **공유 출처 재조회 PASS**. 이 원문은 NotebookLM에 Codex가 먼저 넣은 것이므로 독립 검증 횟수 0 |

따라서 Anti-Gravity의 **MCP 연결은 작동**하지만, 이 재시험만으로 G15E의 구단 명단을 Anti-Gravity가 독립 확인한 것은 아니다. 기존 `NO_VERIFIED_EVIDENCE_PACK`은 *독립적으로 직접 확보한 NBA Evidence Pack 0건*이라는 뜻으로 유지한다. 다음 수집은 접근 가능한 NBA 공식 PDF/보도자료를 파일 읽기까지 완료하고, URL·발행일·본문 위치를 함께 반환해야 통과한다. 설계/원고 게이트와 G16/G17 상태는 바꾸지 않는다.
