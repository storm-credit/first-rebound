## 2. 주요 맹점과 방화벽

| 맹점 | 실패 형태 | 방화벽 |
|---|---|---|
| 신체+인지 이중 천재 과잉 | 약점 없는 선택받은 자 | 기술·전술·권한·자가 창조는 별도 학습과 영구 한계 |
| 공간인지의 초능력화 | 공이 어디로 갈지 항상 앎 | 불완전 정보, 접촉, 시야 차단, 낯선 속도에서 오판 |
| BQ의 자동 상승 | 시즌이 지나면 똑똑해짐 | 실패→해석→훈련→비용→검증→새 카운터 |
| 코치의 장식화 | 주인공이 혼자 모든 답 발견 | 각 단계의 언어·훈련·권한은 지도자가 제공, 실행은 주인공 책임 |
| 라이벌 바보 만들기 | 패스를 못 보는 이기적 득점광 | 초기 BQ는 이미 높음. 약점은 무지가 아니라 성공 방식의 과잉 최적화 |
| 역할 수렴 | 둘 다 레너드형 만능 윙 | 주인공의 1차 창조 상한과 라이벌의 리바운드/연결 비핵심 유지 |
| 영어 치트키 | 미국 적응 갈등 삭제 | 생활 언어와 전술·라커룸·권한 언어 분리 |
| 공격 보상 부족 | 주인공 경기의 카타르시스가 수비뿐 | 리바운드→전환, 숏롤, 세컨드사이드 패스로 가시적 보상 |
| 결말의 정답화 | 마지막 패스가 너무 쉬운 모범 답안 | 슛과 패스 모두 합리적인 상태에서 관계·신뢰·책임이 선택 비용이 되게 설계 |
| 능력 설명 과잉 | BQ 표를 본문에서 강의 | 설정집은 백스테이지. 경기에서는 위치→선택→반응→결과로 증명 |

## 3. 약한 해석 검사

| 용어 | 채택 해석 | 더 약한 해석 | 약한 해석이 만드는 실패 |
|---|---|---|---|
| 천재 | 특정 정보 처리의 높은 천장과 학습 속도 | 무엇이든 빨리 잘함 | 만능화·훈련 무력화 |
| BQ | 상황 인지→선택 우선순위→실행·소통의 복합 능력 | 전술 이름을 많이 앎 | 해설형 주인공, 경기 판단 증명 없음 |
| 대기만성 | 잠복 재능의 적용 범위가 경험을 통해 늦게 확장 | 나이가 들면 자동 완성 | 성장 인과 삭제 |
| 공간인지 | 움직이는 공·사람·빈 공간의 관계 처리 | 미래 위치를 정확히 예언 | 초능력화 |
| 제한적 창조 | 보조 핸들·클로즈아웃·숏롤 창조 | 필요할 때만 에이스급 1대1 가능 | 영구 한계가 무의미해짐 |

정본과 후속 설계는 반드시 채택 해석을 사용한다.
