# Independent Review

- 상태: `NOT_STARTED`
- 원칙: 최종 비평자는 설계 과정의 의도 설명이 아니라 산출물·요구·제약만 받아 검토한다.

## 입력

1. `canon/PROJECT_FREEZE.md`
2. 사용자 요구와 금지사항
3. E0 시대 선택 근거와 선택 시대 사실 연구
4. 세계/인물/신체 정본
5. 역사 기준선과 인과 시뮬레이션
6. Ending/Theme, Act, Sub-Act, 회차 기능표
7. Context Pack 샘플과 무결성 결과
8. Design Gate 수용 기준

## 검수 질문

- 선택 시대가 독자 인지도와 작품 차별성을 함께 갖는가?
- 선택 시대의 규정을 현대 규정으로 잘못 적용했는가?
- 영어 능력이 갈등 제거용 만능키가 되었는가?
- 196→203cm 성장과 기술 전환의 비용이 실제로 존재하는가?
- 강백호·로드맨·《ONE GAME》·《라스트 댄스》의 기능 참고가 사건 복제로 넘어갔는가?
- 주인공이 실존 스타의 커리어를 구경하거나 칭찬받기 위한 장치가 되었는가?
- 주인공이 접촉한 역사만 바뀌고 원거리 세계까지 과장되게 장악하지 않는가?
- 실제 팀·코치·선수가 제도적 이유 없이 비합리적으로 움직이는가?
- 전역 PRIMARY 장치가 2개를 넘거나 Sub-Act 활성 장치가 2개를 넘는가?
- 복선 회수가 정보 공개로만 끝나지 않고 선택·관계·비용·보상 중 하나를 바꾸는가?
- MacGuffin·Red Herring이 스포츠 성장축에 실제로 필요한가?
- Hoffman Unity 기준에서 유명하지만 불필요한 실존 스타·설정·경기가 남아 있는가?
- 모든 Act가 중심 질문을 진전시키고 상태를 바꾸는가?
- 같은 경기 패턴과 성장 보상이 반복되는가?
- 결말의 패스가 관계·전술·주제를 동시에 결산하는가?
- Context Pack이 정본을 왜곡하거나 낡은 값을 담는가?

## 판정

- `PASS`: 수정 없이 게이트 증거로 사용 가능
- `PASS_WITH_NOTES`: 비차단 개선점
- `HOLD`: 조사/결정 전 진행 금지
- `BLOCKER`: 정본 또는 인과를 깨뜨림

`HOLD`와 `BLOCKER`가 하나라도 있으면 Design Gate는 열리지 않는다.
