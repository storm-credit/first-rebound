# Master Workflow

중앙 두 저장소의 필요한 기능만 작품에 맞게 결합한 실행 순서다. 단계는 순차적이지만 연구와 맹점 검토는 필요한 범위에서 왕복한다.

| 단계 | 작업 | 산출물 | 종료 조건 |
|---|---|---|---|
| 0 | Intent/Freeze | 핵심 결정·금지사항 | 사용자 결정과 충돌 없음 |
| 1 | Blindspot/Trap Scan | 위험·미정·복제 가능성 | 치명적 맹점에 소유자 지정 |
| 2 | Research Charter | 시대별 질문·출처 등급 | 주장별 검증 방식 존재 |
| 3 | Ending/Theme | 결말 기능·주제·대가 | 시작과 결말의 변화축 연결 |
| 4 | World/Character Model | 세계 규칙·인물·관계·신체 | 모든 선택의 제약 설명 가능 |
| 5 | Historical Baseline | 원역사 사건 원장 | 연도·날짜·출처·확신도 있음 |
| 6 | Causality Simulation | 접촉·파급·대안 사건 | 강제 복원 없이 결과 계산 가능 |
| 7 | House Style Lock | 단일 문체 규약 | 참고작 모사가 아닌 기능 추출 |
| 8 | Master Architecture | 전체 시즌/커리어 곡선 | 결말까지 변화·비용 누적 |
| 9 | Act Map | Act 목표·압력·선택·상태 변화 | Act마다 주 방법 1~2개 |
| 10 | Sub-Act Map | 하위 갈등과 주/보조 장치 | 각 Sub-Act의 종료 상태 명확 |
| 11 | Unity Review | 인과·주제·POV·역할 통합 | 모순과 중복 없음 |
| 12 | Episode Function Map | 회차별 약속·전환·후크 | 모든 회차가 구조적 기능 보유 |
| 13 | Context Pack Build | 회차별 최소 입력 묶음 | 출처·버전·연속성 검사 통과 |
| 14 | Independent Review | 맹점·정의·현실성·견인력 | BLOCKER/HOLD 0 |
| 15 | Gate Approval | 사용자 승인 | `DESIGN_GATE=OPEN` |

## 최소 오케스트레이션

상시 다중 에이전트를 두지 않는다. 해당 단계에 필요한 역할만 호출한다.

- **Root/Gate Owner**: 현재 단계, 정본, 승인, 범위 통제
- **Evidence Lane**: 공식 규정·기록·시대 자료 수집
- **Narrative Design Lane**: 결말→Act→Sub-Act→회차 기능
- **Historical Simulation Lane**: 접촉 사건과 나비효과 재계산
- **Independent Critic**: 설계에 참여하지 않고 최종 모순·맹점 검토

같은 사실을 여러 역할이 따로 소유하지 않는다. 연구 결과는 권위 문서에 승격된 뒤에만 설계 입력이 된다.

## 반복 루프

각 단계는 `질문 → 4안(중요 결정) → 맹점 훑기 → 선택 → 문서 반영 → 독립 확인 → 상태 갱신` 순서로 닫는다. 질문을 무한히 늘리지 않고, 다음 결정을 실제로 막는 정보만 수집한다.
