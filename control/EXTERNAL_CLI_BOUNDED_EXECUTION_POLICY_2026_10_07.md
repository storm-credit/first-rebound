# 외부 CLI 한정 실행 정책

기존 [Research/Verification Layer v2](RESEARCH_VERIFICATION_LAYER_V2.md)의 실행 보완이다. [관측 및 원문대조](../reviews/WAS_LEGACY_P1_RIGHTS_A09_AND_EXTERNAL_RESPONSE_REVIEW_2026_10_07.md)를 근거로 한다. 기존 정본/게이트/작가선택 규칙을 변경하지 않는다.

1. 목적과 지정입력·원천지문을 먼저 고정한다. 프롬프트 개선, 공식 수집, 지정자료 분석, 독립 반증을 서로 다른 요청으로 둔다.
2. AGY는 확인된 절대경로를 사용한다. 공식 [headless 문서](https://antigravity.google/docs/cli/headless)의 json/stream-json 종료응답을 회수하되 SUCCESS 또는툴완료만으로 답변/원문실독성공을 주장하지 않는다.
3. 짧은AGY/Claude의외부한도140초, NotebookLM지정질의180초/소유프로세스210초는 이번관측에서사용한유한한도다. 모든실행에같은한도를강제하지않고 작업길이에맞춘다. 관측1회55.452초성공을 근거로 이전40/55초를 분석불능의증거로단정하지않는다.
4. 긴 실행은 비동기 session handle로 시작하고60초이내의관측구간으로같은확인된live handle을추적하면서다른작업과진행보고를이어간다. 관측timeout만으로재시작하지않는다. 종료/프로세스외부한도때는소유프로세스만종료하고회수/실패상태를정확히기록한다.
5. 수입결과가불명일때중복수입하지않는다. 명명된같은notebook의정확title/입력SHA를읽기전용으로확인해source ID를회수하고 그source만분석한다.
6. 응답회수와내용정확성을분리한다. 조항/가격/권리는원자료로대조한다. 공식URL본문이UNVERIFIED이면다른수집원의직접raw를연결하되그것을AGY실독으로계수하지않는다. Claude반증도구체행동/권한/조건과대조해수용·기각·수리를기록한다.
7. 동일목적의timeout을매batch무조건반복하지않는다. 새입력/원인근거/실행조건변경이있을때한정검문한다. 실패기록은허위PASS나새무한gate가아니며독립적으로진행가능한프로젝트작업을계속한다.

로그인·계정·전역MCP설정변경/예약생성은이정책에포함되지않는다. 실제외부원문/독립검수/작가승인·원고OPEN은각해당gate의증거를따른다.

## 2026-10-12 공식 HTML 앞부분만 수집된 사례

[실제 회수 진단](../reviews/ANTIGRAVITY_NBA_OFFICIAL_READER_DIAGNOSTIC_2026_10_12.md): 설치 절대경로의 stream-json 최종 답은 회수됐다. NBA의 큰 HTML은 저장 자료가 기사 body 전에 끝났고, 관측한 작은 공식 게시물 API로 입력을 바꾸자 필요한 세 날짜가 들어왔다. API 직접 응답도 HTML 발췌+JSON 배열의 혼합 형식이므로 실제 envelope를 확인한 뒤 파싱한다. 해당 URL 형식을 다른 사이트에 추정 적용하지 않는다.

수집기는 최종답뿐 아니라 실제 저장 artifact를 확인한다. 직접 원문과의 정확한 앞부분 일치·요청 항목의 본문 위치를 검사하고, 부분 자료에 있는 항목만 수집 성공으로 기록한다. 날짜 확인 성공은 전체 기사 실독이나 모든 MCP 연결 성공이 아니다. 모델이 제시한 JavaScript/원 서버 잘림 원인은 직접 자료로 입증되지 않으면 추정으로 남긴다. 전역 설정·로그인 변경이나 무조건 재시도로 해결하지 않는다.
