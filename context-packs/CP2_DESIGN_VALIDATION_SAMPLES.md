# CP2 설계 검증 샘플

- [파생 JSON](CP2_DESIGN_VALIDATION_SAMPLES.json): A06-S3(2021 잠정 결산 연결), A13-S3(결말 기능과 선행 신뢰).
- 상태: `DESIGN_VALIDATION_ONLY_NOT_EPISODE_PACK`. 실제 회차 팩0개·원고0개. [Context Pack 규약](README.md)의 CLOSED 상태 샘플 허용 범위다.
- 현재 검토 기준 main은 PR #325 뒤의 `8cee5a0`이다. 새 샘플은 그 상태의 출처를 검토해 내용 해시로 다시 고정했다. 작업 브랜치에서 갱신한 `control/DESIGN_GATE.md`의 실제 내용도 별도 해시가 고정한다. 기반 커밋 하나가 모든 새 파일을 포함한다는 뜻은 아니다.
- 해시는 UTF-8 파일의 `CRLF`를 `LF`로 정규화한 바이트에 적용한다. 운영체제의 체크아웃 줄바꿈 차이만 무시하며 본문 변경은 여전히 `STALE`로 검출한다.
- 먼저 `python tools/build_cp2_design_packets.py --check`로 검사한다. 정본/설계가 바뀌면 `STALE` 오류가 나며, 근거 검토 없이 builder를 돌려 오류를 숨기지 않는다. 검토된 변경만 기본 builder로 새 해시를 생성한다.
- 2026-09-28 재생성: [Hall 재계약·McGee 거래 생략 선택](../canon/CHICAGO_2020_21_F4_F5_FOLLOWUP_DECISION.json)과 [Markkanen M1 선택](../canon/CHICAGO_2021_MARKKANEN_M1_DECISION.json)을 각 샘플의 참조와 `decision_boundaries`에 연결했다. A06에서 M1은 다음 여름 사건으로만 읽고 2020–21 시즌 결과의 소급 근거로 쓰지 않는다. A13의 2028 Markkanen 소속은 2024–25까지인 M1 제안만으로 확정하지 않는다. 정확 시즌·계약과 실제 회차 기능표가 여전히 HOLD이므로 이 재생성은 G14 최종 PASS가 아니다.
- 2026-09-28 G11 후속: 문피아 참고작 1~5화의 실제 독서 관찰을 반영해 G11 원장·비교표·게이트의 변경된 내용 해시만 검토 후 재고정했다. 추가 사례는 공간·신뢰·후속 비용의 기능 참고이며 재난 폭력 장치를 정본이나 회차 장면에 옮기지 않는다. 21/110회차·본문3/4플랫폼, 실제 회차 Pack0이므로 G11/G14 최종 HOLD를 유지한다.
- 2026-09-28 G1A 후속: [작가가 선택한 Chicago 2021 여름 A 방향](../canon/CHICAGO_2021_M1_OFFSEASON_A_DECISION.json)을 두 설계 샘플에 연결했다. A06에는 2020–21 결과로 소급하지 않는 경계, A13에는 2028 선수 소속을 확정하지 않는 경계를 붙였다. 검사기는 출처 해시와 함께 생성된 샘플의 허용 사실·HOLD·작가 잠금 등 내용 일치와 중복 출처를 검사한다. 이 검사는 실제 회차 Pack의 무결성 PASS가 아니다.
- 2026-09-28 G11 네 번째 플랫폼: [조아라 참고작 1~5화 관찰](../research/STYLE_REFERENCE_ACCESS.md)을 반영해 G11 관련 5개 출처의 변경 내용을 검토하고 해시를 재고정했다. 26/110회차·본문4/4플랫폼이지만 G11 딥리드와 실제 회차 Pack0 상태는 그대로다.
- 2026-09-30 Cleveland C2 후속: [작가가 선택한 Varejão 2021년 5월 복귀 계약 생략](../canon/CLEVELAND_2021_VAREJAO_C2_DECISION.json)을 A06 출처와 HOLD·결정 경계에 연결했다. 35:56 출전분의 치환은 검증 후보이며 실제 건강·등록·급여·시즌 결과는 여전히 HOLD다. 실제 회차 Pack0, G14 최종 HOLD도 유지한다.

| 샘플 | 검증할 기능 | 원고에 넘기지 않을 HOLD |
|---|---|---|
| CP2-A06-S3 | K1/L2/M 결과의 조건부 연결과 실제 사실 분리 | 건강·등록·charge, 전체 소유권/선수 지명 |
| CP2-A13-S3 | 승인된 결말 기능, RC1 선행 상호 비용과 활성 약속 | 2028 대진·시간·점수·잔류·의학·패스 각도 |

이 샘플이 통과해도 사건의 전술적 성공이나 사실 인증이 되는 것은 아니다. 소설 문장·대사·집필 지시를 넣지 않는다. Pack과 정본이 충돌하면 정본이 우선한다.
