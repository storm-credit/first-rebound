# B안 1~4년차 공동 영향과 기존 결과 모델 연결

최신 main `cd041183b49478bd0cff39bc8c6d3f74aab1eaa1`의 B안 날짜별 공격·비득점 역할을 기존 승패 소비부에 연결했다. **작업용 가상 종합 영향 모델**이며 실제 NBA 평점 추정, 정확 점수·정수 박스·개인상 확정이 아니다.

## 적용 범위와 선택 근거

승인된 B 방향과 기존 시즌 설계 실행 위임 안에서, 주인공의 기존 종합 평가에 `+0.5`, 해당 날짜에 실제로 B 슛 기회를 넘긴 동료 각각에 `−0.125`를 주는 작업 가정을 선택했다. 동료 값은 줄어든 기회와 역할 리듬을 함께 시험하는 유효 영향 가정이다. 실존 선수의 능력이 실제로 감소했다거나 부상·임상 사건이 발생했다는 진술이 아니다.

이는 득점으로부터 회귀 추정한 계수가 아니다. B의 앞당긴 자기 공격이 팀 전체 영향에 조금 기여하되, 기존 날짜별 기회 비용도 따로 부담시키는 명시적 가정이다. 임의 가정의 적합성이 승패 보존만으로 증명되지 않는다는 한계를 유지한다. 다른 27개 조합은 스트레스 후보로 남긴다. 기존 승패·픽·계약·플레이오프를 바꾸는 선택은 없다.

```
새 CHI 마진 구간 = 기존 CHI 마진 구간
  + (주인공 사용 초 / 2880) × 선언한 주인공 종합 평가 변화
  + (기회 비용을 부담한 동료 사용 초 합 / 2880) × 동료별 선언한 변화
```

원 모델 네 소비부 모두 개인 영향에 초/2880을 쓴다. 팀 240분 분모로 바꾸지 않는다. PTS·REB·AST·STL을 점수차에 직접 더하지 않는다. 음의 득점 기대 차이는 **누가 이미 기회를 내주었는가**를 찾는 데만 쓰고 평점 변화량을 산출하지 않는다. 새 슛 차감은 없다.

## 구현·재현

- 입력 권위 47개를 LF SHA256으로 고정했다. 현재 P 역할 292출전일과 날짜별 동료 비용을 읽었다.
- 계수 821행: 신인82 + 2년차65×9 + 3년차72 + 4년차82. 서로 다른 모델의 행을 경기 수로 합치지 않는다.
- 12모델 × 주인공7값 × 동료4값 = 336경계 조합. 0/0은 기존 결과를 재현한다.
- 선택된 작업 가정은 **821행 모두 개별 경기 방향 유지**, 신규 동률/불확정 방향 0이다. 같은 시즌 승수만 맞추고 다른 경기를 뒤집은 결과가 아니다.
- 3년차의 기존 미확정 상대 평점 구간을 유지한다. CHI 원정인 행은 홈 구간의 부호와 순서를 함께 바꾼다. 0을 걸치는 구간은 HOLD이며 자동 패배나 연장으로 바꾸지 않는다.
- 기존 1년차 4초 정밀도 이력과 3년차 후반 소수 초 흔적, 2년차 공동코트 정밀도 연결을 보존했다. 원 경기 파일을 덮어쓰지 않았다.

## 실제 확인과 미완료

Codex가 로컬 원 소비부·정확 분수 결과·날짜별 역할을 읽고 구성/재현 검산했다. 신규 Antigravity·NotebookLM·Claude·독립 agent 검수는 실행하지 않았다. Basketball Reference BPM 원 설명은403으로 본문을 읽지 못했다. 이번 법제 질문 답변에는 정부 금메달 명단과 병무청 현재 제도를 웹에서 다시 확인했으며, 이것을 2023 개별 편입 처분 증명으로 쓰지 않는다.

전체 리바운드/어시스트 사건 귀속, 실제 수비 효과, 정확 박스/개인상은 여전히 미완료다. 다음은 동서부 선정 명단·포지션·가상 투표 이유, C01 선택/실행 범위, 현재 역사·최종 회차/Blueprint/Pack이다. 본 연결을 B 전체 완료나 종합 독립검수 통과로 표시하지 않는다.
