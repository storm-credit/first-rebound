## 질문

Portland가 37순위에서 Gary Trent Jr. 대신 Jacob Evans를 선택하면 Trent는 어디에서 처음 포획되는가. 그 선택으로 밀린 선수와 후속 거래는 어디까지 다시 계산해야 하는가.

### 총괄 판정

1. `Lakers 39 Trent`가 현행 1순위 후속안이다.
2. `Detroit 42 Trent`는 Lakers가 실제 내부 보드에서 Bonga의 장기 상한을 Trent보다 앞세웠다고 보는 보수적 대안이다.
3. `Lakers 47`은 하한선이지 추천 착지가 아니다.
4. Trent 미지명은 당시 평가·워크아웃·슈팅 수요와 맞지 않아 거부한다.

정확한 착지는 아직 `LOCK`하지 않는다. 39번 거래 구조는 통과했지만 Lakers가 Bonga보다 Trent를 실제로 앞세웠다는 직접 내부 보드 증거는 없다.

## 계약·육성 계층

Trent는 2라운드 지명자이므로 1라운드 rookie-scale 대상이 아니다. 자연스러운 경로는 다음과 같다.

- 표준 다년 최소급 NBA 계약 후보
- Summer League 참가
- NBA 로스터 경쟁
- 필요시 G League assignment

정확한 보장액·보장 연도·옵션은 착지 팀의 2018 cap과 실제 계약 구조를 대조하기 전 `HOLD`다. 실제 Portland 계약을 Lakers나 Detroit에 복사하지 않는다.

## 39순위 선택 시 2차 연쇄

### Bonga 44 Washington — `PRIMARY_LEAN / NOT_CANON`

- Bonga는 18세 장기 개발형 국제 가드/윙으로 당시 윙 보드에서 평가를 받았다.
- Washington의 실제 44순위 Sanon도 18세 국제 가드의 장기 권리 보유 기능이었다.
- Washington은 Sanon 지명 뒤 `앞에서 좋아하던 선수들이 먼저 지명됐다`고 공개했다. 실제 39순위 Bonga가 44까지 남는 새 입력은 보드를 다시 여는 직접 근거다.
- 따라서 Bonga가 Lakers 39에서 밀리면 Washington 44가 기능상 가장 먼저 열리는 지점이다.
- 다만 그 익명 선호가 Bonga였다는 직접 증거는 없으므로 `LEAN`을 넘지 않는다.

### Sanon 51 New Orleans — `DEMOTED / CARR_KEEP_LEAN`

- New Orleans는 Carr의 6-5 사이즈, 슛, 양 가드 가능성, 대학 득점 생산을 구체적으로 평가했다.
- Carr도 즉시 로테이션이 보장된 선수는 아니었지만, 그것만으로 Sanon과 같은 stash 기능이라고 볼 수 없다.
- Pelicans의 Sanon 직접 평가 기록은 확인되지 않았다.
- 따라서 D-228의 Sanon 51 자동 포획을 철회하고 Carr 유지 쪽을 우세로 둔다.

### Sanon 45~60·미지명 유럽 — `UNDRAFTED_PRIMARY_LEAN`

- Sanon은 동시대 목드래프트에서 30번대부터 50번대 후반까지 편차가 컸다.
- ESPN 계열의 동시대 평가는 mock 42와 big board 63으로도 갈렸다. Washington 한 팀의 고평가가 사라지면 전체 패스가 성립한다.
- 끝까지 선택되지 않으면 NBA out이 있는 기존 Olimpija 계약을 유지할 수 있고 어느 NBA 팀도 draft rights를 갖지 않는다.

2. Bonga 44 Washington의 익명 선호가 실제 Bonga였는지 반증 검토.
3. 2019 AD 거래에서 Washington의 Trent 수용과 2021 RFA·Chicago 3팀 거래 파급 확인.
