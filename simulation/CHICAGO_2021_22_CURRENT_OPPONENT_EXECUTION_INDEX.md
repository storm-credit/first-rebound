# Chicago 2021–22 현재 상대 실행 인계

- 조건부 역할 함수: **29/29팀**, 누락0. 원 DET/NOP2 + TOR1 + 새26.
- 정확한 요청일의 양팀 시계가 준비된 키: **4**. 첫DET/NOP + DET두번째 + TOR첫번째(4조건부 path).
- DET 공개 근거 루틴 가족과 역할을 함께 채택한 키: **2**. DB1조건부 방향과 승패/OT는 별도다.
