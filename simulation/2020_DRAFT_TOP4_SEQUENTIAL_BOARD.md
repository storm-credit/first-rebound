# 2020 Draft Top Four Sequential Board

- 상태: `TOP4_AUTHOR_APPROVED / LOCKED`
- 기준 시점: 2020-11-18 드래프트 직전
- 고정 입력: Minnesota 전체 1순위로 가상 라이벌 지명
- 원고 게이트: `CLOSED`

## 1. 확정 입력

작가 선택 A에 따라 Minnesota는 전체 1순위로 라이벌을 지명한다. 거래는 없다. 실제 1순위 Anthony Edwards는 사라지지 않고 Golden State 2순위부터 다시 팀보드에 들어간다.

이 선택은 라이벌의 정확 공격형·성격·신인 기록을 승인하지 않는다. `대형 감속·템포 공격 지휘자`는 기존 팀 적합도 계산 입력일 뿐 계속 `HOLD`다.

## 2. Golden State 2순위

### 사실

- 드래프트 직전 NBA.com이 취합한 12개 mock 모두 Golden State의 2순위 선택을 James Wiseman으로 봤다.
- 실제 지명 뒤 Bob Myers는 Wiseman이 Golden State 보드의 1위였다고 밝혔다.
- 팀은 Curry·Green·Thompson 코어와 장기 센터를 연결하려 했고, Klay Thompson의 Achilles 부상 뒤에도 Wiseman 선택을 바꾸지 않았다.

### 판정

`James Wiseman AUTHOR_APPROVED / LOCKED`.

Edwards가 새로 남았다는 사실만으로 Golden State가 자동으로 그를 선택하지 않는다. 공개된 구단 보드 진술은 Wiseman 쪽이 더 강하며 작가가 주 분기를 승인했으므로 exact pick을 LOCK한다.

## 3. Charlotte 3순위

### 사실

- 실제 Charlotte는 3순위에서 LaMelo Ball을 지명했다.
- 12개 mock의 종합 prospect 순위는 Edwards 1위·Wiseman 2위·Ball 3위였다.
- Ball을 Minnesota 1순위로 둔 동시대 mock들은 Wiseman 2순위 뒤 Charlotte에 Edwards를 배치했다. 이는 Charlotte가 특정 이름보다 남은 top-three guard를 받는 시장 인식을 보여 준다.
- 그러나 Charlotte가 Edwards와 Ball을 동시에 놓고 공개한 내부 1대1 보드는 확인되지 않았다.

### 판정

`Anthony Edwards AUTHOR_APPROVED / LOCKED`.

당시 종합 평가와 즉시 득점·윙 운동능력을 우선하면 Edwards가 먼저다. 작가는 이 주 분기를 승인했다. Charlotte가 Ball을 유지하는 반대 분기는 선택 전 검토 이력으로 보존하되 활성 정본에서 제외한다.

## 4. Chicago 4순위

### 주 분기: Charlotte가 Edwards 선택

Chicago에는 LaMelo Ball이 남는다. 당시 보도는 Ball이 top four 팀들과만 만났고 4순위까지 떨어지면 Chicago가 반길 것으로 봤다. Coby White·LaVine과 초기 볼 소유·수비 비용은 크지만, 4순위에서 top-three급 1차 창조 상한은 조건부 5인 보드보다 우선한다.

판정: `LaMelo Ball AUTHOR_APPROVED / LOCKED`.

### 반대 분기: Charlotte가 Ball 유지

Chicago에는 Anthony Edwards가 남는다. LaVine과 득점 역할이 겹치지만 Edwards의 당시 전체 1순위급 가치와 윙 운동능력은 Patrick Williams·Haliburton·Avdija보다 앞선다.

판정: `Anthony Edwards REJECTED_HISTORICAL_CONTINGENCY`.

## 5. 순차 보드

| 순번 | 팀 | 주 분기 | 판정 | 반대 분기 |
|---:|---|---|---|---|
| 1 | Minnesota | 가상 라이벌 | `AUTHOR_LOCKED` | 없음 |
| 2 | Golden State | James Wiseman | `AUTHOR_LOCKED` | Edwards 선택/거래는 폐기 검토안 |
| 3 | Charlotte | Anthony Edwards | `AUTHOR_LOCKED` | LaMelo Ball 유지는 폐기 검토안 |
| 4 | Chicago | LaMelo Ball | `AUTHOR_LOCKED` | Anthony Edwards는 폐기 검토안 |

작가 선택으로 **Wiseman 2 → Edwards 3 → LaMelo 4**를 정본화한다. 정확 top four는 `가상 라이벌 → Wiseman → Edwards → LaMelo`다.

## 6. 하류 비용

- LaMelo가 Chicago로 가면 Patrick Williams는 5순위 Cleveland부터 재배열하며 Coby·LaVine·LaMelo의 가드 권한과 수비 조합을 2020-21 player-game에서 다시 계산한다.
- Edwards가 Charlotte로 가면 Charlotte의 Gordon Hayward 영입은 자동 취소하지 않는다. 다만 Edwards·Rozier·Graham·Hayward의 사용률과 wing minutes를 재배분해야 한다.
- Wiseman 유지 시 Golden State의 실제 2020-21 센터 계획은 최소 훼손되지만, Minnesota의 성적 변화가 2021 top-three protected pick의 귀속과 순번에 미치는 영향은 별도 계산한다.
- 어느 분기에서도 실제 신인상·후대 올스타·플레이오프 성과를 2020 팀보드 근거로 사용하지 않는다.
