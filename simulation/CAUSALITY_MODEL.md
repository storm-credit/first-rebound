# Historical Causality Model

## 핵심 명제

“일어날 것은 일어난다”는 원역사의 결과를 강제로 복원한다는 뜻이 아니다. 주인공이 바꾸지 않은 **원인과 압력**은 계속 작동하고, 바꾼 원인은 새로운 결과를 낳는다.

## 사건 등급

| 등급 | 의미 | 처리 |
|---|---|---|
| A: 외부 고정축 | 주인공이 영향을 줄 수 없는 규정·사회·리그 전체 사건 | 날짜와 사실을 고정하되 출처 필요 |
| B: 접촉 사건 | 주인공이 뛴 경기, 입학, 리크루팅, 드래프트, 로스터, 트레이드 | 원결과 폐기 후 인과 재계산 |
| C: 1차 파급 | B로 인해 바뀌는 순위, 출전시간, 평가, 픽, 계약 | 대안 시뮬레이션 |
| D: 원거리 파급 | 여러 매개를 거친 미래 사건 | 확률/범위로 관리, 억지 확정 금지 |
| E: 비가시 영역 | 정보가 없거나 영향 경로가 없음 | 원역사 유지 가능, 단 단정하지 않음 |

## 사건 원장 필드

각 역사 사건은 다음 필드를 가져야 한다.

```yaml
event_id:
date_or_range:
baseline_event:
evidence:
tier:
protagonist_contact:
changed_inputs:
constraints:
candidate_outcomes:
selected_outcome:
downstream_links:
confidence:
status:
```

## 계산 순서

1. 원역사의 직접 원인을 기록한다.
2. 주인공이 실제로 접촉하는지 확인한다.
3. 바뀐 입력만 교체한다.
4. 제도·몸·돈·권한 제약을 적용한다.
5. 최소 2개 이상의 가능한 결과를 비교한다.
6. 선택 결과와 기각 이유를 기록한다.
7. 하류 사건 링크를 갱신한다.
8. 다음 Act의 상태와 모순 여부를 확인한다.

## 금지

- 유명한 결승과 드래프트 결과를 보여주기 위해 억지로 원역사에 복귀
- 주인공이 모든 거래와 우승에 연쇄적으로 관여하는 과대 영향
- 실제 팀이 이유 없이 비합리적으로 행동하게 만들기
- 미래 지식이 없는 주인공이 현대 분석 용어로 정답을 선점하기
- 사소한 경기 변화 하나로 모든 세계가 즉시 뒤집히는 과장

## 설계 안전장치

정확한 NBA 팀과 파이널 시즌은 드래프트·로스터·계약·부상·팀 경쟁창을 연속 시뮬레이션한 뒤에만 잠근다. 결말 기능은 고정하지만 역사 좌표는 계산 결과를 따른다.

## 2018 이후 필수 사건 축

| 사건 | 등급 | 처리 |
|---|---|---|
| 2018 NBA 공격 리바운드 14초 리셋 | A 외부 고정축 | 규칙 고정, 주인공의 2차 공격 판단에 반영 |
| 2018 아시안게임 남자농구 | E 비접촉 기준선 | 주인공·라이벌 불참. 실제 동메달과 경기 결과 유지 |
| 2019-20 NCAA 3점선 확대 | A 외부 고정축 | 라이벌 대학 시즌의 공간·효율 기준 변화 |
| 2020 코비 브라이언트 사망 | A 외부 고정축 | 회귀 없음, 사건 결과 변경 금지 |
| 2020 팬데믹·대학 포스트시즌 취소 | A 외부 고정축 | 라이벌의 평가 과정과 드래프트 절차에 비용 발생 |
| 2020 NBA Draft 1순위 | B/C 접촉·파급 | 주인공의 2018-20 활약으로 순위·픽 소유권을 다시 계산 |
| 2022 전환 저지 take foul 강화 | A 외부 고정축 | 주인공의 리바운드→전환 가치 변화에 반영 |
| 2023 아시안게임 남자농구 | B/C 접촉·파급 후보 | 공동 도전은 LOCK, 최종 12인·전 경기·대진·메달·병역 파급은 R09 재계산 |

전술 변화도 인과 사건이다. 규칙·로스터·코치 철학이 입력이고, 라인업·역할·출전시간·계약이 결과다.
