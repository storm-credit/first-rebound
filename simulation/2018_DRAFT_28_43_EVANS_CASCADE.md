# 2018 Draft Pick 28–43 Evans Cascade

- 상태: `EVANS_37_PRIMARY_LEAN / TRENT_CASCADE_REOPENED`
- 기준 분기: Golden State 28 Chandler Hutchison
- 시간 방화벽: 2018년 드래프트 당시 정보만 사용
- 원고 게이트: `CLOSED`

## 입력

1. Chicago 22는 주인공 후보이며 정확 순번은 아직 HOLD다.
2. 23~27은 실제 선택을 유지한다.
3. Golden State는 28에서 Hutchison을 선택하는 팀 보드 개연성을 통과했다.
4. 실제 28순위 Jacob Evans III가 29부터 남는다.

## 판정 규칙

- Evans가 남았다는 이유로 이후 선수를 한 칸씩 미루지 않는다.
- 각 팀은 실제 선택과 Evans를 당시 필요·보드·워크아웃·거래 의사로 다시 비교한다.
- 실제 선택을 유지하려면 그 팀만의 더 강한 기능 또는 자산 지출 신호가 있어야 한다.
- 미래 NBA 성과는 사용하지 않는다.

## 37 Portland가 가장 자연스러운 종착점인 이유

1. Portland는 Evans를 직접 워크아웃했고, 구단의 목드래프트 정리에서도 Evans가 24순위 후보로 반복 등장했다.
2. 실제로 Portland는 37순위 권리를 얻기 위해 미래 2라운드 두 장과 현금을 지불했다. 이는 해당 구간에서 능동적으로 선수를 고를 의사를 보여 준다.
3. Evans는 당시 후기 1라운드/초기 2라운드 평가, 다포지션 수비, 보조 볼 운반, 3점 표본을 갖고 있었다.
4. 실제 타깃 Trent의 40.2% 3점과 슈팅 중력은 강한 반증이다. 그러나 Evans가 예상 밖으로 남은 새 입력에서는 범용 수비·즉전성이 팀 보드에 재진입한다.

따라서 `Evans 42 Detroit`를 2순위로, 과거의 `Evans 43 Orlando`를 3순위 조건부 분기로 내리고 `Evans 37 Portland → Gary Trent Jr. 후속 보드 재개방`을 현행 주 계산선으로 둔다.

## 37 이후 대안 분기

Portland가 37에서 Trent의 순수 슈팅을 Evans의 범용 수비보다 우선한다는 추가 근거가 확보될 때만 Evans는 계속 내려간다.

1. Detroit 38은 Thomas를 위해 두 미래 2라운드를 지출했으므로 Thomas 유지 우세다.
2. Lakers 39는 Evans를 직접 워크아웃했기 때문에 새 blocker다. Bonga의 장기 플레이메이킹 상한과 계약 구조를 다시 비교해야 한다.
3. Detroit 42는 Evans가 Bruce Brown보다 먼저 선택될 수 있는 2순위 종착점이다.
4. Orlando 43은 세 blocker를 모두 통과한 뒤에만 검토한다.

## Orlando 43 계약 반증

Evans가 세 blocker를 모두 통과해 43에서 Orlando에 가더라도 실제 Justin Jackson의 무계약 draft-rights·G League 경로를 복사할 수 없다.

- Jackson은 어깨 수술 뒤 NBA 표준계약 없이 권리 보유 경로를 탔다.
- 건강한 후기 1라운드급 Evans에게는 다년 표준 최소계약이 더 자연스럽다.
- Orlando의 개막 15인 자리가 사실상 찼으므로 Briscoe 계약 또는 Purvis→Dakari Johnson→Jarell Martin 거래 연쇄 중 적어도 하나가 달라진다.

이 때문에 Orlando 43은 단순한 저비용 종착점이 아니다.
