# Chicago 2019 캡 공간 취득 시점의 예외 산입 경계

기준 main `52f7e43`, 2026-10-04. [원장](CHICAGO_2019_ROOM_ACQUISITION_BOUNDARY.json). **조건부 증명 경로**이며 실제 실행 인증·새 작가 확정은 0이다. 기존 [2019 앵커](CHICAGO_2019_CAP_ROOM_ANCHOR_SCREEN.md)의 부분합이나 [AE](O15F14AE_CHICAGO_OVER_CAP_EXCEPTION_TRIGGER.md)의 하한을 새 계산 완료로 다시 세지 않는다.

## 새로 좁힌 질문

2020년 말의 높은 급여만으로 더 이른 예외 산입액을 지울 수 없다. 대신 기존 승인 경로의 **2019 Satoransky 취득 직전 실제 캡 공간**을 닫을 수 있는지 확인한다. 성공하면 무제한 과거 잔액 추측에 기대지 않고 그 시점의 산입액과 이후 사건을 연결할 수 있다. 이 경로는 S2의 출처 있는 닫힌 구간 또는 완전 분기 증인을 쓰는 방법이며 종료 기준 변경이 아니다.

## 직접 확인한 2017 규칙과 조건부 논증

[NBA 2017 CBA](https://ak-static.cms.nba.com/wp-content/uploads/sites/4/2017/10/2017-NBA-Collective-Bargaining-Agreement.pdf), SHA256 `66d620ebf682e2ffc55698394fb4635d738bf0e0250aad34f9cc137a25bf051a`, 633쪽. 부모와 별도 Codex가 지정 원문을 직접 대조했다. PDF 쪽은 1기준이다.

| 규칙 | PDF / 인쇄 쪽 | 이번 적용 |
|---|---|---|
| I §1(kkk) Room | 32 / 10 | Room은 캡 차액뿐 아니라 예외 사용 자격도 뜻한다. 일반적인 ‘Room 양수’를 캡 공간으로 등치하지 않는다 |
| VII §6(j)(2) | 234 / 212 | 실제 캡 공간으로 취득할 때 수취 Salary ≤ 캡 공간+$100,000. 해당 조항의 §6(m) 단서를 보존한다 |
| VII §6(m)(1)–(2) | 238–240 / 216–218 | 사용 자격과 미사용 예외 산입을 구별한다. 유효하게 산입 중인 비Room 예외는 양의 실제 캡 공간과 양립하지 않는다 |
| VII §6(g) | 231–232 / 209–210 | Room MLE는 별도 항목이며 이번 0 결론에 포함하지 않는다 |

**조건부 추론:** Satoransky 수취 assignment Salary가 정확히 $10m이고 선수 급여 송출 없이 §6(j)(2)의 **실제 캡 차액**으로 적법 취득했다면, 그 직전 캡 공간은 적어도 $9.9m다. 같은 순간 §6(m)(2)에 따라 여전히 Team Salary에 산입 중인 해당 미사용 예외액이 있다면 캡 공간이 소멸하므로 이 양의 캡 공간 증인과 양립할 수 없다. 적법한 자격 종료·사용·만료·포기 처리까지 닫힌 증인에서는 **그 순간의 산입액 0**으로 좁힐 수 있다.

$10m는 기존 2차 기본급 입력을 이용한 시험이다. 실제 수취 Salary·전체 charge·실행 순서를 인증한 값이 아니다. 모든 예외의 역사적 존재·향후 자격이 없다는 결론도 아니다. 이미 쓴 예외의 선수 급여는 계속 별도 산입하며, 이후 새 예외·FA/1R 권리 재산입과 2020 수정 규칙을 따로 검문한다.

## 취득 수단의 유한 분기

구단 [2022–23 가이드](https://chibullsdigital.com/mediaGuide/2022_ChicagoBulls_MG_NBA_HI.pdf) PDF400/인쇄398 본문은 2019-07-07 Satoransky 수취와 draft 자산 송출을 확인한다. 부모가 해당 페이지를 직접 읽고 전체 PDF·쪽 텍스트 지문을 기록했다. 계약 차지·취득 수단·완전한 역사 원장은 이 행에 없다. NBA2019 전망에는 S&T 보도가 있으며 이 거래가 적법한 S&T임을 실행 증인으로 닫으면 다음 두 대안은 계약기간 규칙상 배제된다.

| 조건부 대안 | 직접 규칙 / PDF·인쇄 쪽 | 적법 S&T 증인에서의 경계 |
|---|---|---|
| DPE로 취득 | VII §6(c)(1)(iii), 225 / 203 | 수취 계약 잔여1시즌만 허용 |
| Minimum exception으로 취득 | VII §6(i), 232–233 / 210–211 | 취득 계약 최대2시즌 |
| S&T 자체의 기간 | VII §8(e)(1)(ii), 253–254 / 231–232 | 옵션연도 제외 최소3시즌 |

따라서 위 조건에서 DPE/minimum 경로는 맞지 않는다. 그러나 **기존 비동시 TPE 대안은 남는다**. $10m 수취 시험이면 +$100k 규칙상 최소 잔액 $9.9m가 필요하다. 더 작은 TPE 여러 개를 임의 합산하지 않으며, 명시적으로 허용된 §6(j)의 거래 구성을 별도로 검문한다. Parker/Portis−Porter 순차액만 보고 TPE가 없다고 할 수 없다. Parker 예외를 따로 만들고 Porter를 실제 캡 공간 또는 다른 적법 수단으로 수취하는 구성이 가능한지 당시 전체 상태로 닫아야 한다. **S&T acquiring Team has Room**(§8(e)(1)(vii), PDF254)은 I§1(kkk)의 폭넓은 정의 때문에 캡 공간 사용의 독립 증거가 아니다.

## 실행 증인을 닫는 네 조건 — 현재 모두 HOLD

1. **취득 수단:** 실제 §6(j)(2) 캡 공간 사용. TPE 사용이나 단순 여름 캡 공간 보도와 구별한다.
2. **수취 Salary:** 기본급 보도 대신 적용되는 수취 차지 전체를 닫는다.
3. **직전 전체 상태:** 같은 거래 순서·직전 순간의 전체 Team Salary/캡 차액 증인. 선행 포기 전과 후를 섞지 않는다.
4. **산입 종료 처리:** 해당 미사용 예외의 자격 종료·사용·만료·포기 상태가 적법하게 적용됨을 확인한다.

[NBA 2019 전망](https://www.nba.com/30teams30days/2019/chi)은 여름 캡 공간과 영입을 설명할 뿐 특정 거래 수단을 인증하지 않는다. [Wizards 공지](https://www.nba.com/wizards/wizards-acquire-draft-pick-chicago)는 검색 색인만 읽혔고 부모 직접 본문은 셸, Antigravity도 UNVERIFIED였다. 날짜·자산 색인을 실제 본문 회수나 캡 공간 인증으로 올리지 않는다.

기존 TPE 대안을 지우려면 발생·사용 창도 닫아야 한다. [2018 오프시즌 tracker](https://cdn-uat.nba.com/news/2018-nba-offseason-trade-tracker)의 Grant→Stone 교환과 [2018–19 tracker](https://www.nba.com/2018-19-trade-tracker)의 Holiday·Parker/Portis 송출을 초기 후보로 연결했다. 선수 수취만인 거래와 방출은 Chicago 선수 계약 송출과 다르다. **전체 목록 인증은 아니며**, Grant의 2018-07-07→2019-07-07 당일 경계·분할 TPE 생성 가능성/잔액은 미확인이다. 원역사를 대체 세계의 완전 실행으로 소급하지 않는다.
