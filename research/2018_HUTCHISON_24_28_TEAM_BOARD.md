# 2018 Hutchison Pick 24·28 Team Board Audit

- 상태: `CONTEMPORARY_BOARD_PASS / EXACT_LANDING_HOLD`

- 비교: Portland 24 대 Golden State 28
- 시간 방화벽: 2018년 드래프트 당시 정보만 사용
- 원고 게이트: `CLOSED`

## 질문

Chicago가 22순위에서 주인공을 선택해 Chandler Hutchison이 남았을 때, Portland 24와 Golden State 28 중 어느 팀이 실제 내부 선택 원칙을 덜 훼손하면서 Hutchison을 지명할 수 있는가.

미래의 Simons·Evans·Hutchison 성과는 판정 근거로 사용하지 않는다. 실제 역사 변경량도 목표함수로 사용하지 않는다.

## 동시대 비교

| 기준 | Portland 24 | Golden State 28 |
|---|---|---|
| 실제 선택 | Anfernee Simons | Jacob Evans III |
| 실제 내부 신호 | Simons를 두 차례 워크아웃, Neil Olshey가 해당 구간의 최고 상한을 찾았다고 설명 | Evans를 두 차례 워크아웃, 즉시 약 10분을 맡길 성숙한 다목적 윙을 원함 |
| Hutchison 기능 | 부족한 윙 크기·전환·보조 볼 운반을 보충 | 수비·리바운드·연결·전환을 제공하는 즉전형 윙 후보 |
| 충돌 | 팀이 실제로 택한 `장기 상한` 기준과 충돌 | 실제 Evans의 역할 정의와 직접 중첩 |
| Hutchison 약점 | 외곽슛·수비 일관성이 Lillard–McCollum 보완 요구에 완전히 맞지 않음 | 외곽슛·수비 일관성 때문에 Evans보다 명백한 상위라고 단정할 수 없음 |
| 판정 | `SIMONS_KEEP_LEAN / HUTCHISON_CONTINGENCY_ONLY` | `HUTCHISON_TEAM_BOARD_PASS / NOT_LOCKED` |

## Portland 24 판정

### 사실

- Portland는 Simons를 두 번 워크아웃했다.
- Olshey는 24순위에서 가능한 최고 상한을 찾았다고 설명했다.
- Portland의 당시 자체 목드래프트 정리에는 Hutchison 24 전망도 존재했다.
- Hutchison은 Chicago 약속설 뒤 다른 워크아웃을 중단했으므로 Portland 워크아웃 명단 부재 자체는 거절 증거가 아니다.

### 추론

Portland의 윙 필요만 보면 Hutchison은 자연스럽다. 그러나 실제 선택을 설명하는 가장 강한 내부 증거는 `두 차례 검증한 19세 Simons의 상한`이다. Hutchison이 남았다는 사실만으로 이 기준을 뒤집으면 팀의 실제 판단 철학을 지우게 된다.

### 판정

`SIMONS_KEEP_LEAN / HUTCHISON_CONTINGENCY_ONLY`

Hutchison 24는 가능한 외부 보드 대안이지만 현행 주 분기로 쓰지 않는다. Portland 분기는 폐기하지 않고 Golden State가 28에서 Hutchison보다 Evans를 유지하는 반증 분기로 보존한다.

## Golden State 28 판정

### 사실

- Golden State는 실제로 Evans를 두 번 워크아웃했다.
- 당시 구단 설명은 수비 지향성·리바운드 감각·다목적성·강인함을 Evans의 핵심으로 보았다.
- Kerr와 Myers는 28순위 선수가 다음 시즌에 뛰어야 하며 stash나 매각 대상이 아니라고 밝혔다.
- Hutchison은 22세 고학년으로 복수 포지션, 볼 운반, 패스, 리바운드, 전환 능력을 가진 후기 1라운드급 윙이었다.
- 2018년 6월 18일 NBA/Timberwolves 목드래프트는 Hutchison을 Golden State 28에 직접 배치했다.

### 추론

Evans의 실제 팀 보드 근거는 강하다. 그러나 Hutchison은 Evans보다 볼 운반·전환·보조 창조 범위가 넓고, 나이와 대학 경험상 즉시 투입 조건에도 맞는다. 실제 22순위급 후보가 예외적으로 남아 있다면 Golden State가 두 선수를 다시 비교해 Hutchison을 앞세우는 선택은 충분히 성립한다.

이 판정은 `Golden State가 반드시 Hutchison을 고른다`는 뜻이 아니다. 실제 내부 평가를 이길 수 있는 합리적 후보라는 뜻이다.

### 판정

`HUTCHISON_TEAM_BOARD_PASS / DRAFT_NIGHT_PRIMARY_CANDIDATE / NOT_LOCKED`

팀 보드 개연성은 통과한다. 정확 착지는 Evans의 Portland 37 재착지와 Gary Trent Jr. 후속 보드, 2019 Spellman–Damian Jones 거래, 2020 Russell–Wiggins 거래가 연결된 뒤에만 정본 후보로 승격할 수 있다.

## 워크아웃 맹점

Hutchison의 Chicago 약속설과 워크아웃 중단은 두 방향으로 작용한다.

1. Portland·Golden State가 그를 워크아웃하지 못했다는 사실은 낮은 평가의 증거가 아니다.
2. 동시에 Golden State가 Evans만큼 직접 검증하지 못했으므로 Hutchison 우위를 확정하는 증거도 아니다.

따라서 Golden State 28은 `PASS`까지 올리되 `LOCK`하지 않는다.
