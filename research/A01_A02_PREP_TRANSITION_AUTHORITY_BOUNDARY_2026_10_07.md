# A01 → A02 프렙 전환: 사실·권한·미답 조건

**범위:** 2026-10-07 조사·가상 제도 실행 패킷. [JSON](A01_A02_PREP_TRANSITION_AUTHORITY_BOUNDARY_2026_10_07.json)에 근거와 미답 항목을 기록했다. 기능8·9가 통합된 `main` `75a1d526` 기준으로 E9 원천 검문과 중앙 포함 8개 파일의 정규화 SHA-256을 다시 확인했다. 이는 파일 현재성 검문이며 실제 학생의 입학·비자·학점·NCAA 자격 판정이 아니다.

## 이미 잠긴 결과와 현재 관측

- [진로 연표](../canon/CAREER_TIMELINE.md)·[Freeze](../canon/PROJECT_FREEZE.md): 주인공은 한국 고1 뒤 **2016년 3월 가상 뉴잉글랜드 소규모 보딩 프렙으로 이동**하는 방향이다. 2017년 5~6월 졸업창과 훗날 NCAA full qualifier 경로도 정본 목표다.
- [E9](../design/A01_E9_FINAL_EPISODE_FUNCTION.md)의 국소 관측: 본인은 미답 학업·입학 조건을 남겨 두고 그 방향을 계속 준비하겠다고 기존 한국 고교 감독에게 전한다. 이 행동은 위의 미래 이동 결과를 뒤집지 않는다. 또한 실제 입학 통지·서류 발급·비자·출국을 인증하지 않는다.
- [A02 조건부 기능](../design/A02_PREP_CONDITIONAL_FUNCTIONS.md)의 S1은 도착 뒤 학업 도움 요청, 게임·수면 실패가 낳는 실제 기회 상실, 그 후 자기 순서의 시험이다. 10개 단위는 후보이며 A02 최종 회차/실제 Pack은 0이다. A02 잠정 진입의 생활 영어와 학업 자격 혼동은 E8/E9에서 검증된 상태나 해결된 상태가 아니다.

## 이미 잠긴 이동을 가능하게 하는 가상 실행안

기존 정본은 2016년 3월 이동을 정했으므로, 가상학교에 실재 DHS 검색 행이 없다는 이유로 모든 서사 진입을 영구 보류하지 않는다. 다음 **여섯 결과의 종류**를 기존 방향을 구현하는 *가상 설계 선택*으로 둔다. 실제 사람·학교의 기록 인증이나 새 작가 경로 선택은 아니다. 국무부 본문과 권한 순서를 대조한 독립 검문에서 이 한정 범위가 수용됐다. 2014 DHS 문서는 직접 열기 오류를 검색 본문 읽기와 구분하고, NCAA 2011 링크의 리디렉션은 당시 원문 전체를 재회수했다는 주장으로 쓰지 않는다.

| 순서 | 가상 설계 선택 | 아직 정하지 않는 값 |
| --- | --- | --- |
| F1 | 가상 사립 보딩 프렙이 F-1 수용 가능한 학교이며 주인공을 2016년 3월 편입 대상으로 받아들인다 | 교명·입학 심사 기준·실물 통지 |
| F2 | 보호자 동의와 필요한 재원 경로가 존재한다 | 사람의 상세 역할·금액·동의 문서 |
| F3 | 학교의 DSO가 수락 뒤 SEVIS 학생 기록을 만들고 I-20을 발급한다 | 번호·발급일·실물 문서 |
| F4 | 이 가상 사례에서 학생비자가 발급된다 | 인터뷰일·수수료·비자번호·개별 심사 이유 |
| F5 | 2016년 3월 학교 도착을 위해 입국이 허용된다 | 출발/입국일·공항·I-94 |
| F6 | 도착한 학교의 학업 담당자가 잠정 수업 배치와 도움 경로를 설명할 수 있다 | 한국 과목별 환산·정확 시간표·졸업 감사·NCAA 인증 |

F1과 F2의 정확한 선후는 미지정이고 둘 다 F3·F4 전에 놓는다. F3→F4→F5→F6 순서다. **E9의 감독에게 전한 의사는 F1–F6 어느 기관 결정도 아니다.** 감독은 의사를 듣거나 추천할 수 있으나 입학·I-20·비자·입국·NCAA 인증을 대신하지 않는다.

## 다음 설계에 실제 필요한 연결

1. **가상 프렙 자체의 판단:** F1의 수락 결과는 기존 이동 방향을 구현하는 가상 설정이다. 한국 과목의 정확한 인정·교명·개별 통지는 HOLD다. 코치나 주인공이 입학을 승인한 것은 아니다.
2. **국제학생 경로:** F3–F5는 서로 다른 가상 기관 결과다. E9의 의사만을 근거로 문서·비자·입국을 관측했다고 소급하지 않는다. 실물 번호·시점·심사 내용은 정하지 않는다.
3. **A02-S1의 첫 기능 후보:** F6을 전제로 도착 뒤 가상 프렙 학업 담당자에게 부족한 과목과 도움을 묻는 행동은 기존 A02-CF01 범위 안에서 설계 가능하다. 현재는 정확 과목·GPA·시간표·NCAA 환산이 없으므로 회차나 실제 학교 기록으로 승격하지 않는다.
4. **나중 NCAA 인증:** 한국·프렙 7학기 구성과 16개·10/7 등의 정본 목표는 유지한다. 학교의 조언, 감독 추천, 대학 영입은 NCAA Eligibility Center와 대학 입학·compliance 결정을 대신하지 않는다.

가장 가까운 후속은 **A02-S1 학업 도움 요청의 국소 설계**다. 수용된 F1–F6 가상 실행안을 토대로 학업 담당자의 권한과 주인공에게 보이는 도움 요청 행동을 구체화한다. 실명·실물 기록은 사실 미인증의 한계이며 이 가상 경로를 위한 새 필수조건은 아니다. A01의 계획 잔여27슬롯을 새 사건 없이 숫자로 채우지 않는다. 설계/원고 게이트 `CLOSED`, `manuscript_allowed:false`, 전체 G13/G14·실제 Context Pack·원고는 미완료다.
