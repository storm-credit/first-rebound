# Research Program

- 상태: `CHARTER_APPROVED / EVIDENCE_NOT_COLLECTED`
- 원칙: 검색 결과 요약은 단서일 뿐, 정본 근거가 아니다.

## 출처 등급

- **P1**: 당시 공식 규정집, NCAA/NBA/협회 문서, 경기 기록, 계약/CBA 원문
- **P2**: 당시 신문·방송·인터뷰·학교 기록·경기 영상
- **P3**: 신뢰 가능한 회고·전기·학술/전문 분석
- **P4**: 현대 요약 기사·팬 위키·커뮤니티 — 탐색용, 단독 정본 금지

모든 항목에 `주장 / 기준일 / 적용 기간 / 출처 / 접근 상태 / 확신도 / 정본 승격 위치`를 기록한다.

## 참고작 트랙

참고작은 사실 연구와 분리한다. 실제 텍스트를 합법적으로 읽지 못한 경우 `METADATA_ONLY`로 표시하고 딥리드로 부르지 않는다.

| 대상 | 추출할 기능 | 접근 상태 | 복제 방화벽 |
|---|---|---|---|
| 《슬램덩크》 | 초보가 종목과 팀을 사랑하게 되는 변화의 단계 | ACCESS_TO_CONFIRM | 사건·대사·인물 관계·외형 복제 금지 |
| 《라스트 댄스 - NBA DREAM》 | NBA 커리어 연재의 보상 주기 비교 | METADATA_ONLY | 회귀 장치와 천재 재도전 구조 사용 금지 |
| 《ONE GAME》 | 한국→NCAA→NBA 경로의 시장 비교 | ACCESS_TO_CONFIRM | 최고 유망주 출발과 사건 배열 복제 금지 |
| 데니스 로드맨 경기 자료 | 박스아웃, 타구 궤적, 반복 점프, 심리전 | PUBLIC_FACTS/VIDEO_TO_REVIEW | 성격·외형·인생 서사 복제 금지 |

## 딥리드 출력

딥리드는 작품별 문체 모사가 아니라 다음만 산출한다.

- 장면 기능
- 정보 공개 속도
- 경기/비경기 비율
- 성장 보상의 간격
- 반복 장치와 변주 방식
- 독자가 다음 화를 누르는 질문
- 우리 작품에 적용할 원칙과 금지 원칙

결과는 단일 `HOUSE_STYLE`에 합쳐야 하며, 작가 이름을 흉내 내는 지시는 금지한다.
