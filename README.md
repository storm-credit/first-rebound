# first-rebound

- 정식 제목: `HOLD — 시대 선택 뒤 확정`
- 태그라인 후보: **처음 배운 것은 리바운드였다**
- 장르: 회귀·시스템·빙의 없는 현실 역사 농구 성장 웹소설

한국 고교에서 농구를 늦게 시작한 원석형 포워드가 미국 프렙스쿨과 NCAA를 거쳐 NBA에 도전한다. 주인공은 2017-18 Villanova에서 한 시즌을 보내 NCAA 우승 뒤 2018 NBA Draft에 진입하고, 동갑 라이벌은 한국 고교 부상과 재활 뒤 NCAA에서 복귀해 2020 NBA Draft에 도전한다.

> 현재 단계: **R02 TIMELINE / DESIGN ONLY — 원고 집필 금지**

설계서·설계도·세계 모델·고증 원장·인과 시뮬레이션·Act/Sub-Act·회차 기능표·Context Pack·독립 검수가 모두 통과되어 `control/DESIGN_GATE.md`가 `OPEN`으로 바뀌기 전에는 프롤로그와 1화를 포함한 어떠한 원고도 작성하지 않는다.

## 현재 고정된 중심

- 장르 장치: 회귀·시스템·빙의 없음
- 진로 구조: 한국 고교 → 미국 프렙 → 2017-18 Villanova NCAA 우승 → 2018 NBA 드래프트 → NBA
- 신체 성장: 약 196cm의 농구 초보 → 약 203cm의 다재다능한 투웨이 SF/PF
- 핵심 질문: 재능만 있던 사람이 팀의 마지막 선택을 맡길 수 있는 선수가 될 수 있는가?
- 결말 기능: NBA 파이널 7차전, 마지막 수비와 리바운드 뒤 직접 슛이 아니라 동료의 결승 득점을 만드는 패스
- 모티브 경계: 강백호형 성장 기능만 참고하고 사건·관계·대사·외형은 독자 창작. 데니스 로드맨은 리바운드 기술 연구 범위로 제한
