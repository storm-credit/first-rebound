# 처음 배운 것은 리바운드였다

1998년 한국 고교에서 농구를 처음 시작한 원석형 포워드가 미국 프렙스쿨과 NCAA를 거쳐 2004년 NBA 드래프트에 도전하는 현실 역사 스포츠 웹소설 프로젝트입니다.

> 현재 단계: **DESIGN ONLY — 원고 집필 금지**

설계서·설계도·세계 모델·고증 원장·인과 시뮬레이션·Act/Sub-Act·회차 기능표·Context Pack·독립 검수가 모두 통과되어 `control/DESIGN_GATE.md`가 `OPEN`으로 바뀌기 전에는 프롤로그와 1화를 포함한 어떠한 원고도 작성하지 않습니다.

## 고정된 중심

- 장르 장치: 회귀·시스템·빙의 없음
- 시대 경로: 1998 한국 고교 → 미국 프렙 → NCAA → 2004 NBA 드래프트 → NBA
- 선수 성장: 약 196cm의 농구 초보 → 약 203cm의 다재다능한 투웨이 SF/PF
- 핵심 질문: 재능만 있던 사람이 팀의 마지막 선택을 맡길 수 있는 선수가 될 수 있는가?
- 결말 기능: NBA 파이널 7차전, 마지막 수비와 리바운드 뒤 직접 슛이 아니라 동료의 결승 득점을 만드는 패스
- 모티브 경계: 강백호형 성장 기능은 참고하되 사건·관계·대사·외형은 독자 창작, 데니스 로드맨은 리바운드 기술 연구 범위로만 제한
