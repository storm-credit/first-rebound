# World Model

현실 스포츠물의 세계관은 지도나 마법 체계가 아니라, 선수가 선택할 수 있는 길을 제한하는 **제도·돈·몸·문화·기록의 작동 규칙**이다.

## 세계의 층

| 층 | 포함 항목 | 설계 질문 |
|---|---|---|
| 한국 고교 농구 | 학교, 협회, 대회, 합숙, 지도자 권한, 스카우팅 | 1998년 초보가 공식 경기에 들어갈 현실적 통로는 무엇인가? |
| 가족/교육 | 전학, 학적, 비용, 보호자 동의, 병역 인식 | 미국행 선택의 실제 비용과 반대는 무엇인가? |
| 미국 프렙 | 입학, 비자, 학비/장학, 학사, 팀 일정, 노출 캠프 | 영어가 되는 외국인 선수가 경기 자격과 평판을 얻는 과정은? |
| NCAA | 당시 자격 심사, 리크루팅, 장학, 훈련 제한, 토너먼트 | 주인공의 한국·프렙 학력이 2001~2004 규정에서 어떻게 처리되는가? |
| NBA | 2004 드래프트 자격, 컴바인, 워크아웃, CBA, 로스터, 계약 | 어느 팀이 어떤 정보로 주인공을 평가하고 감수하는가? |
| 농구 기술 | 시대별 스페이싱, 수비 규칙, 포지션 관습, 분석 지표 | 현대식 포워드 능력이 당시에는 어떤 이름과 한계로 보이는가? |
| 신체/의학 | 성장, 체중, 부상, 회복, 훈련 과학 | 능력 향상마다 몸이 치르는 비용은 무엇인가? |
| 문화/언어 | 인종, 이민, 라커룸, 미디어, 팬, 한국 보도 | 번역이 아닌 권력·유머·침묵의 의미를 어떻게 오해하는가? |
| 경제/미디어 | 방송, 에이전트, 신발 계약, 지역 시장 | 성적이 평판과 기회로 바뀌는 통로는 무엇인가? |
| 역사 외부 사건 | 실제 시즌, 노동 분쟁, 규정 변화, 사회 사건 | 주인공과 무관하게 유지되는 압력은 무엇인가? |

## 세계관 확정 규칙

1. 실제 규정은 해당 연도의 공식 또는 1차 자료를 우선한다.
2. 현재 규정을 과거에 소급하지 않는다.
3. 날짜가 없는 사실은 연표에 넣지 않는다.
4. 조사 결과는 `VERIFIED / DISPUTED / INFERRED / HOLD`로 표시한다.
5. 허구 학교·팀을 사용할 경우 실제 제도 안에서 작동하도록 모델링한다.
6. 실제 팀/선수를 사용할 경우 주인공 접촉 이후 결과는 `simulation/`에서 계산한다.
