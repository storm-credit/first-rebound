# World Model

현실 스포츠물의 세계관은 지도나 마법 체계가 아니라, 선수가 선택할 수 있는 길을 제한하는 **제도·돈·몸·문화·기록의 작동 규칙**이다. 구체 연도는 E0 시대 선택 뒤 적용한다.

## 세계의 층

| 층 | 포함 항목 | 설계 질문 |
|---|---|---|
| 한국 고교 농구 | 학교, 협회, 대회, 합숙, 지도자 권한, 스카우팅 | 선택 시대의 초보가 공식 경기에 들어갈 현실적 통로는 무엇인가? |
| 가족/교육 | 전학, 학적, 비용, 보호자 동의, 병역 인식 | 미국행 선택의 실제 비용과 반대는 무엇인가? |
| 미국 프렙 | 입학, 비자, 학비/장학, 학사, 팀 일정, 노출 캠프 | 영어가 되는 외국인 선수가 경기 자격과 평판을 얻는 과정은? |
| NCAA | 당시 자격 심사, 리크루팅, 장학, 훈련 제한, 토너먼트 | 선택 연도의 한국·프렙 학력이 당시 규정에서 어떻게 처리되는가? |
| NBA | 선택 드래프트의 자격, 컴바인, 워크아웃, CBA, 로스터, 계약 | 어느 팀이 어떤 시대적 평가 기준으로 주인공을 감수하는가? |
| 농구 기술 | 시대별 스페이싱, 수비 규칙, 포지션 관습, 분석 지표 | 투웨이 포워드 능력이 당시에는 어떤 이름과 한계로 보이는가? |
| 신체/의학 | 성장, 체중, 부상, 회복, 훈련 과학 | 능력 향상마다 몸이 치르는 비용은 무엇인가? |
| 문화/언어 | 인종, 이민, 라커룸, 미디어, 팬, 한국 보도 | 번역이 아닌 권력·유머·침묵의 의미를 어떻게 오해하는가? |
| 경제/미디어 | 방송, 인터넷, SNS, 에이전트, 신발 계약, 지역 시장 | 선택 시대의 미디어가 평판과 기회를 어떻게 바꾸는가? |
| 역사 외부 사건 | 실제 시즌, 노동 분쟁, 규정 변화, 사회 사건 | 주인공과 무관하게 유지되는 압력은 무엇인가? |

## 세계관 확정 규칙

1. E0 시대를 먼저 선택한다.
2. 실제 규정은 해당 연도의 공식 또는 1차 자료를 우선한다.
3. 현재 규정을 과거에 소급하지 않는다.
4. 날짜가 없는 사실은 연표에 넣지 않는다.
5. 조사 결과는 `VERIFIED / DISPUTED / INFERRED / HOLD`로 표시한다.
6. 허구 학교·팀은 실제 제도 안에서 작동하게 한다.
7. 실제 팀/선수와 접촉한 뒤의 결과는 `simulation/`에서 다시 계산한다.

## v0.12 미국 프렙·NCAA 작동 규칙

- 주인공의 학교는 가상 뉴잉글랜드 소규모 보딩 프렙이다. 실존 학교는 국제학생·기숙사·학업지원·농구 노출의 기능 근거로만 사용한다.
- 프렙 농구 감독은 영상 추천과 체육 평가를 담당한다. registrar는 이전 학점과 졸업을, Villanova 입학처는 입학을, compliance와 Eligibility Center는 NCAA 출전 자격을 각각 판단한다.
- 2016년 3월 편입 뒤 한국 네 학기와 미국 세 학기를 합쳐 2017년 5~6월 7학기 조기졸업을 한다. 결석 기록이나 부족 학점은 농구 재능으로 삭제되지 않는다.
- 의무 스터디홀·튜터·보충과목은 벌의 장식이 아니라 훈련·게임·외출 시간을 빼앗는 실제 비용이다.
- 2017 Villanova 영입은 프렙 감독 추천→실전 평가→학업 진행 재확인→늦은 체육장학금의 한 경로만 사용한다.
- 대학 구간의 상세 권위와 재개 조건은 `research/COLLEGE_EXIT_PACKET.md`와 `control/COLLEGE_ARC_SCOPE_GATE.md`를 따른다.

## v0.13 부상·레드셔츠 작동 규칙

- 의학적 복귀는 달력 하나가 아니라 부종·가동범위·근력·균형·기능검사·경기 심리를 단계별로 통과해야 한다.
- 2018-19 라이벌은 NCAA에 full-time 등록하지만 공식 경기에는 0회 출전한다. 5년 clock은 시작하고 경기 시즌 하나는 보존하는 전통적 레드셔츠로 처리한다.
- 이미 사용한 시즌을 되돌리는 hardship waiver와 처음부터 경기하지 않는 레드셔츠를 혼용하지 않는다.
- 대학 감독은 수술·복귀 clearance·입학·NCAA 인증을 단독으로 결정하지 못한다. 의료진·입학처·compliance·Eligibility Center 권한을 분리한다.
- 부상 전 장학금 오퍼 유지와 대학 선택은 `research/RIVAL_INJURY_REDSHIRT_MODEL.md`의 조건을 만족하는 학교만 후보로 둔다.

## v0.14 Gonzaga·실존 로스터 작동 규칙

- 라이벌의 학교는 Gonzaga다. 국제선수가 여러 명인 실제 로스터는 적응 가능한 환경의 근거일 뿐 자동 친분·자동 입학의 근거가 아니다.
- 2018-19 공식전 0경기라도 장학금 counter·입학·Eligibility Center·의료 권한은 실제 제도 안에서 작동한다.
- 2019-20 라이벌의 분과 점유율은 기존 선수 기록 위에 더하지 않고 실제 팀 총분·공격 지분에서 재배분한다.
- 깊은 실존 관계 3명·대표 경기 2개·재활 비용 1축 상한을 넘지 않는다.
- WCC 우승 기능과 2020 NCAA 토너먼트 취소는 잠그되 실제 31승 2패·개인 기록은 R09에서 재계산한다.
- 대학 범위 재개 조건은 `control/RIVAL_COLLEGE_SCOPE_GATE.md`가 통제한다.

## v0.15 Atlanta·NBA assignment 작동 규칙

- 주인공은 2018 Draft 30순위 Atlanta 1라운더다. rookie-scale NBA 계약, 투웨이 계약, G League 표준계약을 혼용하지 않는다.
- NBA 계약 선수의 G League assignment는 계약 해지·call-up이 아니다. Atlanta가 권리를 유지하고 회수할 수 있다.
- 2018-19 제휴팀은 Erie BayHawks, 2019-20부터는 College Park Skyhawks다. 두 팀명을 같은 시즌에 혼용하지 않는다.
- 실제 30순위 Spellman의 존재와 후속 경로를 삭제하지 않으며 R09가 드래프트 보드를 재계산한다.
- 주인공의 분과 기록은 실제 Atlanta 선수 총분 위에 더하지 않는다. Young·Huerter·Collins의 핵심 공로도 자동 축소하지 않는다.
- G League는 지각의 직접 징계가 아니다. 직접 비용은 NBA 기회 상실이고, assignment는 그 뒤 경기 반복을 확보하는 별도 권한 결정이다.
- 첫 NBA 착지 범위 재개 조건은 `control/NBA_LANDING_SCOPE_GATE.md`가 통제한다.
