# B안의 실제 사용 작업 모델 선택

B 방향과 기존 위임으로 이미 구현한 작업 입력을 Pack이 읽을 수 있는 선택 객체로 연결했다. 새로운 수상·금메달·최종 회차 수를 선택한 문서는 아니다.

## 선택한 사용 범위

B1–4년차의 날짜별 자기 공격·동료 기회 비용과 기존 비득점 기대 prior를 명시적 가상 작업 입력으로 사용한다. 총영향 P+1/2·실제 기회비용 동료각−1/8은 기존 선택 승패 방향을 보존하는 위임 모델이며 실측 평점이 아니다. 연차별 인정 경쟁은 사용하되 실제 수상·득표·정수 박스 기록은 사용하지 않는다. 2023 누적 성장에 B 보너스를 다시 더하지 않는다.

|NBA 연차|시즌|기존 역할 날짜|기대 득점/경기|인정 경쟁|
|---|---|---|---|---|
|1|2018–19|73|8.00|올루키|
|2|2019–20|65|12.00|MIP|
|3|2020–21|72|17.01|올스타|
|4|2021–22|82|20.00|올스타·All-NBA|

위 수치는 작가용 기대 입력이며 실제 정수 박스 기록이나 선수의 현재 지식이 아니다. 리바운드·어시스트 사건의 공동 귀속까지 인증하지 않는다. 분·시작권·동료 기회 비용과 각 발표 이전 정보 창을 유지한다.

821개 영향 행을 분수로 재계산해 12개 기존 모델의 방향 보존을 확인했다. 2년차21–22승 범위의 정확 기록은 여전히 미선택이며, 2023 누적 성장에는 B 점수/평점 보너스0을 유지한다.

## 후행 연결

- 사용 포트: FC012–FC022(11개). 정규 수상은 NOT_USED; 경쟁 기능은 사용한다.
- 현행 역사 연결이 이 원 선택 객체의 path/hash/pointer/resolution을 참조한다.
- C01 FC031/032/040의 달력, 최종N·분류 정책, 현행 개별 설계의 독립 수락과 실제 Pack은 남는다.
- 원고0·Pack0·v0.30 PARTIAL/CLOSED. 신규 외부 CLI·독립검수0.
