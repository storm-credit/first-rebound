# 한국 고교 첫 감독 — 인물 카드 v0.1

**현행 정본 기능을 구체화한 일상 인물 설계.** 작가가 지적한 ‘농구부 체험 초대가 뜬금없다’는 인과 공백을 해결하기 위한 카드다. 이름·나이·학교 안의 정확한 신분·선수 경력은 미정이며, 전직 프로·국가대표·해외 인맥을 임의로 만들지 않는다.

## 기존 정본과 이번 구체화

기존 기능은 우연한 공 반응 관찰 → 조건부 체험 제안 → 첫 훈련/동갑 앞 완패 → 기본기 학습, 그리고 후행 프렙 비교 자료 전달이다. 이번 선택은 이 기능의 **이유와 지도 기준**이다. 새 경기·점수·결과·기관 허가를 추가하지 않는다.

| 항목 | 현재 인물 설계 |
|---|---|
| 자기 목표 | 좋은 신체 조건을 실제로 반복 훈련하고 팀에서 믿고 맡길 수 있는 수행으로 키우고 싶다. |
| 관찰 방식 | 눈에 띈 반응을 더 볼 이유로 삼고, 한 행동으로 선수의 완성도나 미래를 판정하지 않는다. |
| 초대 이유 | 큰 신체와 직접 본 공 반응에 관심을 갖는다. 농구 경험을 묻고, 훈련에서 발 움직임·지시 수행까지 확인하려 한다. |
| 초대의 범위 | 조건부 체험이다. 선수 선발·대회 등록·장래 진로를 약속하지 않는다. |
| 일대일의 목적 | 상대에게 당한 뒤 무엇을 보고 대응을 바꾸는지 관찰한다. 체험생의 신체 우위와 기술·판단·위치 부족을 구분한다. |
| 지도 방식 | 허용된 짧은 과제 → 관측 가능한 수행 → 현재 부족한 한 가지 → 다음 기본 과제로 연결한다. |
| 장점 | 결과만 보지 않고 실제 동작에서 가능성과 부족을 함께 찾는다. |
| 약점 | 자신에게 명백한 동작을 초보도 알아들을 것이라 여겨 설명이 짧아질 수 있다. 불필요한 모욕·기회 박탈로 표현하지 않는다. |
| 태오를 대하는 기준 | 한 번의 좋은 반응은 체험할 이유다. 시간 준수·수업·보충 조건과 수행 능력은 별개로 확인한다. |
| 지한을 대하는 기준 | 숙련된 선수의 과제를 분명히 정한다. 체험생을 위한 비교에 참여할 때도 지한의 훈련·선택·기여를 남긴다. |
| 말투 | 현재 행동과 다음 과제를 짧고 구체적으로 말한다. 질문에 답하고, 미래의 성공이나 선수의 속마음을 단정하지 않는다. |
| 권한 | 농구부 훈련의 참여·과제를 정한다. 담임/학교의 출결 처분, 의료진의 진료, 프렙의 입학·학사 결정은 대신하지 않는다. |

## 초대의 인과

**관찰한 신체·공 반응 → 경험 확인 → 아직 모르는 움직임·지시 수행을 더 볼 필요 → 조건 있는 방과 후 체험.**

작가는 이 연결을 초대 이전이나 초대와 가까운 문맥에 보여 준다. 감독의 상세 이력이나 속마음 설명을 넣어야 성립하는 초대로 만들지 않는다. 학생이 ‘왜 나를 부르지?’에 답할 수 있는 관찰 또는 말이 있어야 한다.

로컬 1화 초고에는 두 번째 공을 던지고 받는 동작이 이미 있다. 이는 당시 읽은 초고의 실행이며, 추가 테스트·세기·횟수를 정본 규칙으로 고정하는 근거는 아니다. 감독에게 반응이 보였다는 사실과 태오가 감독의 비공개 평가를 안다는 주장은 구분한다.

## 회차별 사용 위치

- **1화/FC001:** 체험 초대의 이유를 먼저 연결한다. 비교 훈련은 학습 반응 관찰로 해석한다. 완패·출석 경고·태오의 자존심을 유지한다.
- **2화/FC002:** 첫 리바운드/아웃렛 기여 이후의 기본 박스아웃 과제로 이어진다. 1화에서 박스아웃 해법이나 반복 숙련을 미리 가르치지 않는다.
- **3화/FC003:** 기존 자기 준비와 동료 부담을 남기는 기능 안에서 사용한다. 추가 처벌·새 성과를 만드는 수단으로 쓰지 않는다.
- **4화/FC004:** 기존 미국 환경 비교·이동 준비의 범위에서 자료를 전달한다. 한국어 한 장의 안내가 학교 합격·장학금·비자 보증이나 감독의 해외 인맥 증거가 되지 않는다.

모든 위치는 **기존 Pack과 함께 읽는 인물 설계 입력**이다. 현재 선수 시점에서는 직접 본 행동·들은 말·전달된 자료만 사용한다. 카드의 자기 목표·약점은 작가의 인물 모델이며 태오에게 자동으로 알려지지 않는다.

## 아직 정하지 않은 것

이름, 정확한 나이, 지도 경력, 교사/학교운동부 지도자 등의 정확한 신분, 임용·계약 관계는 미정이다. 이를 사용하는 장면이 생기면 별도로 확정한다. 임의의 유명 선수 출신·개인 비극·부원 부족·학생 부상·구단 인맥으로 현재 초대 이유를 메우지 않는다.

## 반영과 검수의 범위

설정 카드와 현재 작업 진입점만 추가했다. 61개 발급 Pack과 기존 승인 자료는 보존한다. 본문 수정은 실행하지 않았으며 이 카드의 존재를 원고 수리 완료로 세지 않는다. 로컬 EP0001 초고의 당시 버전은 별도 문맥 자료이며 정본 원고 승격이 아니다. v0.30 PARTIAL / 설계·원고 CLOSED 유지.
